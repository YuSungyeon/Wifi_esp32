# 진폭 학습기 (amp60)

> 상태: **EXPERIMENTAL** — 공식 산출물이 아니다. 담당자의 배포 체크포인트는
> `model_train/robust/model.pt` 이고 그 코드는 담당자가 유지한다.

담당자의 구조(`SharedEncoder`)와 입력 변환(`amplitude_input`)만 import 하고, 학습 루프·세션
선택·체크포인트는 우리 것을 쓴다. 담당자의 `run_experiment.py` 는 문서화된 60세션 고정이라
(`len(sessions) != 60` 이면 거부) 임의 세션 선택에 쓸 수 없기 때문이다.

## 두 가지 과제 (`--task`)

어휘는 파일럿 `model_train/cnn1d/cv_pilot.py` 의 `TASKS` 와 같다. 라벨 매핑이 두 곳에서
어긋나면 안 된다.

| `--task` | 클래스 | 체크포인트 `mode` | 쓰임 |
|---|---|---|---|
| `3class` (기본) | empty / static / motion | `A-ours` | 배포 모델과 같은 입력으로 세션을 골라 학습 |
| `motion` | rest / motion | `A-motion` | **1단계** — 짧은 창 움직임 검출, 화면 활동량 |

`empty`/`static` 전용 모델은 **두지 않는다.** 파일럿에서 3-class 보다 나빴다(0.852 < 0.877) —
motion 세션이 빠지며 학습 데이터가 3분의 2로 줄고, 움직임도 "사람이 있다"를 가르친다.

## 체크포인트

| 파일 | 과제 | 창 | 학습 | 평가 | 결과 |
|---|---|---|---|---|---|
| `model_motion3s.pt` | motion | **3초** | 9/16·17·19 45세션 | **봉인 9/20 단발** | 세션 30/30 · 창 정답률 0.9661 |

`model_motion3s.pt` 의 창 단위 동작 (9/20, `stage1_eval.py`):

| | 창 수 | 평균 | 중앙값 | 95%ile |
|---|---:|---:|---:|---:|
| rest | 19,673 (1.64시간) | 0.051 | 0.044 | 0.077 |
| motion | 9,909 (0.83시간) | 0.834 | 0.909 | 0.967 |

| 기준 | 연속 창 | 덮는 시간 | 움직임 창 비율 | rest 오경보 |
|---:|---:|---:|---:|---:|
| 0.70 | 3 | 3.6초 | 0.838 | 4.3회/시간 |
| 0.70 | 10 | 5.7초 | 0.838 | 1.2회/시간 |
| 0.90 | 3 | 3.6초 | 0.549 | **0회** |

**비교**: 배포 진폭 30초 모델은 20초짜리 움직임도 한 번도 보고하지 못한다
([realtime-inference.md](../../doc/realtime-inference.md) §4).

**"움직임 창 비율 0.838" 은 놓침률이 아니다.** motion 세션 300초 내내 사람이 움직이지 않으므로
멈춘 구간을 rest 로 보는 것은 맞는 동작이다.

**기준값은 아직 고르지 않았다.** 위 표는 선택지일 뿐이다. 봉인 데이터로 운영점을 고르면 그
순간 시험지가 아니게 된다 — 전환 세션(realtime-inference.md §7)을 수집한 뒤 정한다.
그래서 1단계는 상태 기계에 들어가지 않고 화면에 활동량으로만 나온다.

## 쓰는 법

```bash
# 1단계 학습 (약 80초, seed 3개, Apple MPS)
python model_train/amp60/train.py --name motion3s --task motion --window 300 \
    --train 20260916 20260917 20260919 --eval 20260920

# 창 단위 오경보·최소 감지 시간
python model_train/amp60/stage1_eval.py --model model_train/amp60/model_motion3s.pt \
    --dates 20260920

# 3-class — 세션을 골라 학습 (제어판 학습 탭이 이것을 부른다)
python model_train/amp60/train.py --name 내실험 --sessions 20260916_31 ... --eval 20260919
```

학습·평가 날짜가 겹치면 **거부한다.** `cache/` 에는 세션별 진폭이 쌓이며 git 에 올리지 않는다.

## 한계

- `transition_test.py` 의 "끼운 구간 최대값" 방식은 **짧은 창에 쓸 수 없다.** 창이 3초면 세션
  하나에 창이 1000개라 최대값은 행동이 아니라 분포의 꼬리를 잰다 — 정지 세션에서도 끼우지
  않은 상태로 p_motion 최대 0.896 이 나온다. 그래서 `stage1_eval.py` 를 따로 뒀다.
- rest 1.64시간은 전부 9/20 이다. 9/10 빈 방 6세션은 `load_raw_amplitude` 가 공통 구간 부족으로
  거부해 기여가 없다.
- 피험자 1명·단일 방. 장시간 운영과 전환 구간은 검증하지 않았다.
