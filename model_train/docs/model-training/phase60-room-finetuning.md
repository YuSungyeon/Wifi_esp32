# 기존 위상 모델을 이번 방 자료로 추가 학습하고 실시간 시험하기

> 상태: **EXPERIMENTAL** — 2026-10-13 추가 학습·GUI/CLI 선택 연결 완료. 새 실시간 성능은 미확인.

## 이번에 할 일

기존 위상 **3클래스 모델**의 CNN과 입력 규칙을 유지하고, 10/12에 수집한 자료로 마지막 분류 부분을 파인튜닝한다. 새 가중치를 별도 파일로 저장한 뒤 GUI에서 선택해 실시간으로 시험한다. 2단계 구조 설계는 후속 후보로 보존한다.

출발 파일은 `model_train/phase60/model_60sessions.pt`다. 입력은 기존 60초·156신호·300시점, 출력은 empty/static/motion, seed 0·1·2의 확률 평균이다.

서비스 목표는 **새 방에 장치를 설치하고 짧게 상태별 측정을 한 뒤, 해당 방·장치 배치에 맞춰 추가 학습해 사용하는 것**이다. 첫 성능 확인은 추가 학습 때의 장치 배치를 유지한 새 녹화로 한다. 이 녹화는 가중치 조정에 쓰지 않고 기존/추가 학습 모델을 같은 입력으로 비교한다. 같은 날 학습 직후에 시험해도 되며, 학습에 쓴 겹치는 창을 시험에 다시 넣지 않는다.

## 학습 자료와 설정

- 새 방 자료는 [첫 측정 확인](20261012-room-adaptation-capture.md)의 잠정 구간 105창(empty 36·motion 35·static 34)을 사용한다. 휴대전화/Mac 시차 0초와 경계 양끝 10초 여유 가정도 기록한다.
- 기존 60세션의 정답은 `session.json`에서 읽는다. 기존 세 능력 유지를 위해 유효한 겹치지 않는 60초 창을 추가 학습에 섞는다.
- 기존/새 방을 같은 비중으로 추출하고, 각 출처 안에서 세 클래스 비중을 맞춘다.
- seed별 기존 가중치에서 시작한다. CNN 가중치·BatchNorm 통계는 고정하고 `head`(128→64→3)만 학습한다.
- 최초 Adam 학습률 1e-4·20 epoch 시도는 학습 자료에서도 구분이 악화됐다. 다음 시도를 원래 모델에서 다시 시작해 **학습률 1e-3·배치 32·고정 100 epoch**로 학습했고 실시간 시험 후보로 연결했다. 검증 기반 최적 설정 선택이 아니라 학습 자료를 보고 설정을 조정한 것이다.
- 고정 CNN의 특징을 seed별로 미리 계산할 수 있다. 이 경우 원래 전체 순전파와 같은 값을 내는지 대조한다.

## 입력·원본 확인

학습 전에 파일 해시·CRC·헤더·RF·수신기 식별·순번·부팅 경계를 검사한다. 이번 RX103 재부팅은 선택 구간 밖에 있고, 각 입력 창은 한 부팅과 한 정답 구간 안에 있어야 한다. 누락은 기존 규칙대로 최대 5프레임 내부 보간만 허용한다.

원본 실시간 `session.json`은 혼합 상태에 맞게 null 라벨을 유지하고, 정답은 확인 보고서의 별도 구간 정보로 연결한다. 출발 가중치와 사용자 원본을 덮어쓰지 않는다.

## 확인과 해석

학습 전후 이번 자료와 기존 재학습 자료의 점수·혼동표를 저장한다. **둘 다 학습 자료에 대한 점수**이며 독립 정확도라고 부르지 않는다. 새 방에는 이번 녹화 1회만 사용하며, 학습한 녹화의 겹치는 창을 검증·시험으로 나누지 않는다.

저장 모델을 다시 읽어 같은 입력의 예측을 대조하고, CNN·BatchNorm과 출발 모델의 불변을 확인한다. 새 실시간 녹화에서 empty/static 구분과 motion 유지 여부를 실제로 확인한다. 현재 자료만으로 성능 개선을 확정하지 않는다.

[10/6 비교](20261013-room-finetuning-oct6-evaluation.md)는 RX별 위치와 삼각대 사용 여부가 10/12와 다른 조건의 평가다. 10/12 배치에서 적응 후 사용하는 성능을 대신하지 않는다. 새 방이나 변경한 배치에서 다시 짧게 측정·학습하는 흐름의 확인과, 한 번 학습한 모델을 다른 배치에 그대로 적용하는 확인은 각각 기록한다.

## 실시간 연결

새 파일은 `model_train/phase60/model_room_20261012.pt`, 모델 선택 이름은 **위상 60초 · 내 방 추가 학습**으로 한다. 종류 키는 `phase60_room`이며 실제 입력 경로는 기존 `phase60`을 재사용한다. 같은 60초 준비·기본 0.3초 이동·세 클래스 즉시 표시를 적용한다.

기존 위상 모델과 새 파일을 따로 선택할 수 있게 한다. 새 파일에는 출발 모델 해시, 추가 학습 자료, 사용 설정, 독립 시험 미실시 상태를 기록한다. 새 선택에는 추가 학습 메타데이터가 없는 원래 가중치를 넣지 못하게 검사한다.

GUI에서 **위상 60초 · 내 방 추가 학습 → 실시간 시작**으로 새 보드 시험을 시작한다. CLI는 `--model-kind phase60_room`을 사용한다. 모델 변경은 현재 판단을 정지한 뒤 새 실행에서 적용한다.

실제 수치·파일 해시·실행 방법은 [추가 학습 결과](20261013-phase60-room-finetuning.md)에 있다.
