# 쉽게 읽는 3분류 모델 학습 결과

> 상태: **SUPPORTING ANALYSIS — 2026-09-24 완료된 학습 결과의 쉬운 해설**
> 자세한 수치와 검증 파일은 [원래 결과 보고서](robust-three-class-report.md)가 기준이다.
> 왜 이런 방식으로 시험했는지는 [쉬운 설계 설명](robust-three-class-design-easy.md)에 있다.

## 먼저 결론

**기존 60세션으로 모델 학습을 마쳤다.** 선택한 방식은 30초 동안의
**상대 진폭**을 보는 작은 CNN을 세 번 따로 학습하고, 세 모델의 답을 평균하는
것이다. `empty`(빈 공간), `static`(가만히 있는 사람), `motion`(움직임)을 고른다.

기존 두 날짜 자료에서 정해 둔 평가 기준은 통과했다. 이후 최종 저장 파일을
**9월 16·17일 자료에 적용하니 30초 구간 280개 중 234개(83.57%),
세션 15개 중 12개(80.00%)를 맞혔다.** 빈 방과 정지를 서로 헷갈리는 문제가 남아 있다.
자세한 결과는 [9월 16·17일 최종 모델 평가](20260916-17-model-evaluation.md)에 있다.

## 모델에는 무엇을 넣나

수신기 3대에서 진폭 신호를 17개씩 골라 **총 51개 신호**를 쓴다. 신호마다
최근 **30초**를 보고, 절대 크기 대신 **그 신호의 30초 평균에 비해 얼마나
변했는지**를 계산한다. 30초의 3,000개 원래 시간값을 10개씩 평균해
신호마다 **300개 시간값**으로 줄인다.

CNN은 51개 신호를 같은 규칙으로 하나씩 검사한다. 그리고 세 상태에 대한
점수를 낸다. 이 구조를 시작값만 바꿔 **세 번 따로 학습**했다. 예측할 때는
세 모델의 점수를 평균한다. 수신기 3대와 모델 3개는 서로 다른 이야기다.
최종 선택 모델은 **진폭만** 쓰며 위상은 쓰지 않는다.

![같은 CNN으로 51개 신호의 특징을 추출한 뒤 하나의 방 상태를 판단하는 구조](shared-cnn-explanation.png)

CNN 안의 합성곱은 **시간축 한 칸씩 이동(stride 1)**한다. 첫 두 합성곱은
시간값 5개씩 보며 **양끝에 0 두 개씩 붙인다(padding 2)**. 마지막 합성곱은
3개씩 보며 **양끝에 0 한 개씩 붙인다(padding 1)**. 그래서 합성곱은 시간값
개수를 유지한다. 첫 두 합성곱 뒤의 평균 풀링은 2개씩 평균하고 2칸씩 이동해
개수를 `300 → 150 → 75`로 줄인다. 풀링에는 padding이 없다.
여기서 CNN의 stride와 아래의 **윈도 이동 간격 15초**는 서로 다른 설정이다.
전체 층 설정은 [구조 상세 설명](robust-three-class-pipeline.md#4-공유-시간-인코더의-실제-구조)에 있다.

30초짜리 판단 구간은 **15초씩 이동**한다. 처음 판단하려면 최소 30초를
모아야 한다. 15초 간격이 최선인지 따로 비교한 것은 아니다.


## 60세션을 어떻게 썼나

처음에는 **9/19의 30세션을 6세션씩 5묶음**으로 나눴다. 각 묶음에는
`empty`·`static`·`motion` 세 상태가 **2세션씩** 들어간다. 한 묶음을 평가용으로
빼놓고 나머지 네 묶음(24세션)으로 모델을 처음부터 학습한다. 평가 묶음을
바꿔 가며 이를 5번 반복한다.

| 차례 | 학습에 쓰는 묶음 | 평가에 쓰는 묶음 |
|---|---|---|
| 1 | 2·3·4·5 | 1 |
| 2 | 1·3·4·5 | 2 |
| 3 | 1·2·4·5 | 3 |
| 4 | 1·2·3·5 | 4 |
| 5 | 1·2·3·4 | 5 |

그래서 **30세션 모두가 한 번씩 평가 자료**가 된다. 10초 진폭, 30초 진폭 등
모델 후보마다 같은 5번의 분할을 적용하고 결과와 차례별 점수 차이를 비교해
사용할 모델 구조를 골랐다. 이 과정에서 학습된 다섯 모델 중 하나를 그대로
최종 파일로 쓰는 것은 아니다.

그다음에는 **시험할 자료를 먼저 빼놓고, 남은 자료로 모델을 새로 학습했다.**
‘같은 모델 구조’란 CNN의 층과 계산 방법은 같다는 뜻이다. 앞에서 학습한
가중치를 그대로 가져오는 것이 아니라, 평가할 조건마다 처음부터 다시 학습했다.

날짜를 바꿔도 맞는지 확인할 때는 다음처럼 나눴다.

- **9/20을 시험하는 경우:** 9/20의 30세션 전부를 학습에서 제외한다.
  9/19의 30세션으로 학습한 뒤, 빼놓은 9/20의 30세션에서 얼마나 맞는지 확인한다.
- **9/19를 시험하는 경우:** 반대로 9/20의 30세션으로 새로 학습한 뒤,
  학습에서 제외한 9/19의 30세션에서 확인한다.

수신기 배치도 같은 방식으로 확인했다. 예를 들어 **P1 배치를 시험할 때는
P1에서 수집한 24세션 전부를 빼놓고**, P2·P3의 나머지 36세션으로 학습한 뒤
P1의 24세션에서 확인했다. P2와 P3도 각각 빼놓고 별도로 학습·평가했다.
이것은 수신기 한 대를 빼는 것이 아니라 **그 배치에서 수집한 세션 전체를
학습에서 빼는 것**이다.

자료는 30초 구간 하나씩 무작위로 나누지 않고 **세션 전체를 한쪽에만 배정했다.**
예를 들어 같은 세션의 `0~30초`와 `15~45초`는 15초가 겹친다.
첫 구간을 학습에, 다음 구간을 평가에 넣으면 같은 신호 일부를 양쪽에서 보게 된다.
그래서 어떤 세션이 평가용이면, 그 세션에서 나온 모든 30초 구간을 학습에서
제외했다. 학습용 세션의 구간 역시 그 평가의 시험 자료에 넣지 않았다.

아래 점수는 이렇게 **평가 자료를 빼놓고 따로 학습한 모델들**의 성적이다.
마지막에 60세션 전체로 다시 학습한 파일과는 학습에 사용한 자료가 다르다.

**마지막에 저장한 `model.pt`는 60세션 전부로 다시 학습한 파일**이다.
30초 구간 후보 1,133개 중 결측이 있는 9개를 제외해 **1,124개 구간**을
사용했다. 모델 3개를 각각 **15 epoch** 학습했다. 1 epoch은 그 학습 구간들을
한 번씩 보는 것이다. 이 최종 학습에서는 60세션 안에 별도 검증·테스트
세션을 남기지 않았다.

## 얼마나 맞았나

아래는 **최종 파일의 시험 점수가 아니다.** 표의 각 방향마다 평가 날짜를
학습에서 제외하고 따로 학습한 **평가용 모델**의 점수다.

| 학습 → 평가 | 30초 구간별 정확도 | 각 세션의 첫 30초 | 약 5분을 모은 세션 판정 |
|---|---:|---:|---:|
| 9/19 → 9/20 | 97.31% | 30/30 | 30/30 |
| 9/20 → 9/19 | 95.59% | 28/30 | 30/30 |

**30/30 세션 판정**은 약 5분 동안 나온 여러 30초 구간의 결과를 평균했을 때
30세션을 모두 맞혔다는 뜻이다. 한 번의 30초 판단이 늘 맞는다는 뜻은 아니다.
두 번째 방향의 첫 30초에서 틀린 2세션은 실제 `static`인데 `empty`라고 했다.

수신기 배치 P1·P2·P3를 각각 빼고 평가한 세션 판정도 `24/24`, `18/18`,
`18/18`이었다. **새로운 60세션을 추가로 평가한 숫자가 아니라**, 같은
60세션을 다른 방식으로 나누어 다시 확인한 것이다. 배치가 같아도 방 안의
다른 조건이 완전히 같았다는 뜻은 아니다.

## 후보 선택까지 다시 검사한 이유

처음 30초 진폭 모델을 고를 때 **9/19의 세션을 보며 후보를 비교했다.**
따라서 그 뒤에 9/19의 세션을 평가에 사용하면, 그 자료는 학습에 들어가지
않았더라도 **어떤 모델을 고를지 결정하는 데 이미 쓰인 자료**다. 9/19 평가
점수를 완전히 처음 보는 자료의 점수라고 해석하기 어려운 이유다.

이를 확인하려고 **시험할 자료를 모델을 고를 때부터 따로 빼두는 절차**도
실행했다. 예를 들어 9/19를 시험할 때는 다음 순서다.

1. 9/19의 30세션을 치워 둔다. 후보를 고르고 학습하는 동안 사용하지 않는다.
2. 9/20의 30세션 **안에서만** 10초/30초, 진폭/위상 후보를 비교해 하나를 고른다.
3. 선택한 방법으로 9/20 세션만 사용해 모델을 **처음부터 새로 학습**한다.
4. 마지막에 치워 둔 9/19의 30세션으로 성적을 확인한다.

9/20을 시험할 때는 날짜를 바꿔 같은 순서로 진행했다. P1·P2·P3 배치를
각각 시험할 때도 해당 배치 세션을 먼저 치워 두고 나머지 세션 안에서만
후보를 골랐다. 이렇게 하면 시험 자료가 **학습에도, 후보 선택에도** 쓰이지
않는다. 날짜 두 방향과 배치 세 조건, 총 다섯 조건 모두 미리 정한 기준을
통과했다.

이 절차에서 9/19를 치워 두었을 때는 **10초 진폭**, 9/20을 치워 두었을
때는 **30초 진폭+위상**이 선택됐다. 즉 위 표의 고정된 30초 진폭 모델
성적과는 **다른 검증**이다. 30초 진폭이 언제나 가장 좋은 후보라는 결론도
아니다. 이 후보 선택 절차를 검증할 때 사용한 자료는 기존 두 날짜의 60세션이다.
이후 9/16·17 자료의 추가 평가는 이미 저장한 최종 모델을 그대로 사용한 별도 작업이다.

## 어디까지 확인했고 무엇이 남았나

원본 `.csi` 파일 180개의 식별·해시를 다시 확인했고, 1,124개 모델 입력을
원래 정렬 자료에서 재생성해 일치함을 확인했다. 저장 모델을 다시 읽어 예측
경로가 동작하는지도 확인했다. 다만 이 확인에 쓴 원본 세션 예시는 **학습에
포함된 자료**이므로 독립 정확도 시험이 아니다.

그 후 최종 파일을 학습에 포함되지 않은 9/16·17의 15세션에 적용한 결과가
위의 **234/280, 12/15**다. 같은 날짜·세션 번호의 과거 파일럿 사용 기록이
있으므로, 프로젝트에서 처음 접하는 자료로 시험했다고 표현하지는 않는다.

아직 확인하지 못한 것은 다음과 같다.

- 과거 후보 비교에도 쓰지 않은 **새 날짜·새 환경**에서의 추가 성능 확인
- 사람이 들어오거나 나가는 **상태 전환 중** 오경보와 반응 지연
- GUI·실시간 스트림에서의 실제 동작

현재 파일은 `model_train/analysis/output/20260924-robust-three-class/neural/model.pt`에
있다. **9/19↔9/20 표는 평가용 모델의 성적**, **9/16·17 추가 평가는 이 최종
파일을 직접 실행한 성적**이다. 서로 다른 평가이므로 구분해서 읽는다.
