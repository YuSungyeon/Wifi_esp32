# 75세션으로 진폭·위상 모델 다시 비교하기

> 상태: **EXPERIMENTAL** — 2026-10-30. 기존 모델을 교체하지 않는 별도 파일럿.

## 1. 알고 싶은 것

9/16·17·19·20의 75세션에서 어느 모델이 날짜가 바뀌어도 empty·static·motion을
잘 구분하는지 비교한다. 특히 static을 empty로 판단하는 오류를 확인한다.
이미 여러 실험에 사용한 자료이므로 새로운 독립 시험이라고 부르지 않는다.

## 2. 후보와 공통 학습 조건

- 진폭: 기존 `robust.shared_temporal.SharedEncoder(A)`와 `amplitude_input`.
- 위상: 기존 `cnn1d.shared_cnn.SharedTemporalCNN`과 `phase60.features`의 기본 위상 잔차.
- 각각 15·30·60초, 총 6후보. 진폭은 10Hz·51신호, 위상은 5Hz·156신호 입력.
- 모델 구조·톤 선택·다운샘플링·구조 내부 증강은 기존 것을 보존한다. 비교 대상은
  **두 모델 처리 과정 전체**이며 결과를 입력 종류만의 효과로 해석하지 않는다.
- 공통: seed 0·1·2, 15 epoch, batch 32, AdamW(lr=0.001, weight_decay=0.01),
  cross entropy(label_smoothing=0.1). 평가 점수로 epoch를 고르지 않는다.
- 학습 창 끝 간격 15초, 평가 창 끝 간격 3초. 실시간 0.3초와 다른 오프라인 비교 간격이다.
  계산량을 제한한 사전 고정 파일럿 조건이며 기존 결과의 재현 실험은 아니다.

## 3. 똑같은 구간을 비교하기

라벨은 `session.json`에서 읽는다. 원본과 소스 코드의 SHA-256을 기록하며 별도 캐시를 만든다.
각 세션의 RX 공통 TX 순번 구간을 맞추고 중복 순번은 기존처럼 첫 프레임을 쓴다.
진폭과 위상 모두 유효한 60초 구간의 끝점을 기준으로 15·30·60초 창을 만든다.
모든 후보가 같은 세션의 같은 시점에서 평가된다. 초반 15~60초와 결측 주변은
공통 구간 평가에서 제외하고 제외량을 기록한다. 짧은 창의 빠른 시작 장점은 반영되지 않는다.

기존에 라벨 문제가 기록된 `20260919_12`는 모든 후보의 학습에서 제외한다.
평가는 s12를 포함한 75세션과 제외한 74세션을 둘 다 보고한다. 주 비교는 74세션이며
새로 모델이 틀린 자료를 임의로 제외하지 않는다. 원본 라벨을 바꾸지 않는다.

## 4. 학습과 평가를 나누는 방법

| 비교 | 학습 | 평가 |
|---|---|---|
| 날짜 제외 1 | 9/17·19·20 | 9/16 |
| 날짜 제외 2 | 9/16·19·20 | 9/17 |
| 날짜 제외 3 | 9/16·17·20 | 9/19 |
| 날짜 제외 4 | 9/16·17·19 | 9/20 |
| 조건 묶음 1 | 9/16·17 | 9/19·20 |
| 조건 묶음 2 | 9/19·20 | 9/16·17 |

같은 세션의 창이 학습과 평가에 나뉘지 않는다. 6후보 × 6분할 × 3seed = 108회 학습.
두 조건 묶음은 사람이 다르지만 날짜·배치도 함께 달라져 사람만의 효과를 분리할 수 없다.

## 5. 결과를 읽고 고르는 방법

각 seed와 세 모델의 확률 평균에 대해 창/세션 혼동행렬, 정확도, 클래스별 재현율,
macro F1, static→empty·empty→static 비율을 저장한다. 세션 판정은 창들의
클래스 확률 평균에서 가장 큰 클래스로 정한다.

주 순위: 날짜 제외 4회의 **날짜별 창 macro F1 평균**. 각 날짜 안에서는 세션마다 같은
비중으로 계산해 창 수가 많은 세션이 점수를 지배하지 않게 한다. 같은 수준이면
최악 날짜 성능·static→empty 오류·seed 편차·짧은 창을 함께 보고 결론을 낸다.
조건 묶음 양방향 결과도 별도로 공개한다. 겹치는 창을 독립 표본으로 취급한 통계 주장은 안 한다.
