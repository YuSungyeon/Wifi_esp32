# 쉽게 읽는 위상 모델의 앉기 오판 원인 분석

> 상태: **SUPPORTING ANALYSIS** — 2026-10-08 분석 결과의 쉬운 설명.
> 작성일: 2026-10-12. 새로운 실험 결과를 추가한 문서가 아니다.
> 상세 수치·계산 방법의 기준 문서: [원인 분석 원문](20261008-phase60-static-diagnosis.md).

## 먼저 무슨 일이 있었는가

10/6에 방에서 걷다가 의자에 앉아 가만히 있었던 자료를 저장된 위상 모델에 다시 넣었다. 모델은 앉기 구간을 정지로 제대로 구분하지 못했다. 그 구간의 정지 표시 일치율은 0%였고, 대부분 빈 방으로 판단했다. 이 결과는 위상 모델로 당시 실시간 운영한 기록이 아니라, 저장된 원본을 나중에 위상 모델로 재생한 결과다.

분석에서 가장 뚜렷하게 확인한 것은 **과거 정지 자료와 이번 앉기 자료의 신호 변화 모양이 다르다는 점**이다. 모델은 과거 정지 자료에서 흔했던 천천히 이어지는 변화에 반응했다. 이번 앉기 자료에는 그 특징이 약했다.

아래 1~4번은 원문과 같은 순서로 설명한다. 숫자 나열 예시는 이해를 위한 가상 값이며 실제 측정값이 아니다.

## 1. 변화의 크기보다 시간에 따른 모양이 달랐다

### 여기서 보는 신호는 무엇인가

수신기 3대에서 각각 52개 위상 신호를 사용하므로 총 156개 신호를 본다. 각 신호의 60초 자료를 전처리한 뒤 시간에 따라 어떻게 변하는지 확인했다. 여기서 말하는 변화량은 **위상값의 흔들림 정도**이며, 진폭 크기나 모델 정확도가 아니다.

### 비슷하게 흔들려도 모양은 다를 수 있다

예를 들어 두 신호가 아래처럼 변한다고 생각하면 된다.

- 천천히 이어지는 신호: `0 → 1 → 2 → 3 → 2 → 1 → 0`
- 갑자기 튀는 신호: `0 → 3 → 0 → 2 → 1 → 0 → 3`

둘 다 값이 변하지만 첫 번째는 조금 전 값과 지금 값이 비슷하게 이어진다. 두 번째는 오르내림이 불규칙하다. 흔들리는 크기만 보면 이런 차이를 놓칠 수 있다.

### 실제로 무엇이 달랐는가

| 비교한 특징 | 과거 학습 정지 | 이번 앉기 | 뜻 |
|---|---:|---:|---|
| 시간 연속성 | 0.754 | 0.124 | 이번에는 가까운 시점의 값이 비슷하게 이어지는 성질이 약했다 |
| 느린 변화 비중 | 74.67% | 30.86% | 이번에는 전체 변화 중 천천히 변하는 부분의 비중이 작았다 |

표의 값은 분석한 60초 구간들의 대표값인 중앙값이다. **0.754가 정확도 75.4%라는 뜻은 아니다.** 시간 연속성은 0.2초 떨어진 값들이 얼마나 비슷한지 측정한 수치다. 1에 가까울수록 비슷하게 이어진다.

느린 변화 비중은 전체 신호 변화 중 느리게 변하는 성분이 차지하는 비율이다. 그 비율을 측정했다고 해서 호흡을 검출한 것은 아니다.

과거에는 이번 앉기와 비슷한 크기로 흔들리면서도 정지로 잘 맞힌 신호가 있었다. 따라서 **이번 오판을 단순히 “신호가 너무 약했다”로 설명하기는 부족하다.** 분석한 연속성과 느린 변화 비중에서 이번 앉기는 과거 정지보다 빈 방에 가까웠다.

## 2. 모델이 시간 모양을 중요하게 보는지 직접 시험했다

1번은 자료를 관찰한 결과다. 2번에서는 입력을 가상으로 조작해서 모델의 판단이 바뀌는지 확인했다. 원본 파일이나 저장 모델의 가중치를 수정한 것은 아니다.

### 시험 A — 이번 앉기의 흔들림을 더 크게 만들기

이번 앉기 신호의 변화 폭을 0.5배부터 6배까지 바꿨다. 시간 순서는 유지했다.

**앉기 3개 구간 모두 어떤 배율에서도 정지로 바뀌지 않았다.** 변화 폭이 커지면 움직임으로 바뀌기도 했다. 크기만 키운다고 정지 특징이 살아나는 것은 아니었다.

### 시험 B — 과거 정지 신호의 시간 순서를 섞기

원래 정지로 맞히던 입력의 값들은 그대로 두고 순서만 섞었다.

예를 들어 `0 → 1 → 2 → 3`을 `2 → 0 → 3 → 1`로 바꾸면 사용한 값은 같고 평균과 표준편차도 같다. 그러나 시간에 따라 이어지는 모양은 달라진다.

실제 진단에서 이렇게 처리하자 **원래 정지로 맞히던 14개 구간이 모두 빈 방으로 바뀌었다.** 모델이 값의 크기뿐 아니라 시간에 따른 모양을 중요하게 사용한다는 근거다.

### 시험 C — 이번 신호를 천천히 이어지는 모양으로 만들기

주변 시점의 값을 평균해 급격한 변화를 줄인 뒤, 흔들림 정도를 원래 수준으로 다시 맞췄다. 그러자 이번 앉기 3개 구간 모두 정지로 바뀌었다.

하지만 빈 방에도 같은 처리를 하자 **빈 방 4개 구간까지 모두 정지로 잘못 판단했다.**

이 결과는 모델이 그런 시간 모양에 반응한다는 증거다. 신호를 부드럽게 만드는 처리를 해결책으로 바로 적용하면 빈 방 오판이 늘어날 수 있다.

## 3. 평균을 빼는 전처리 때문에 어떤 정보가 사라질 수 있다

위상 모델은 각 신호의 60초 평균을 뺀다. 그러면 그 신호가 평균 주변에서 어떻게 변했는지가 입력에 남는다.

이해를 위해 가상 값 네 개만 사용하면 다음과 같다. 실제 모델은 이런 계산을 신호별 60초 자료에 수행한다.

| 상태 | 평균을 빼기 전 | 평균 | 평균을 뺀 결과 |
|---|---|---:|---|
| 빈 방 | `10, 11, 10, 9` | 10 | `0, 1, 0, -1` |
| 사람 있음 | `20, 21, 20, 19` | 20 | `0, 1, 0, -1` |

두 상태의 원래 평균은 달랐지만, 평균을 빼고 나면 같은 값이 된다.

**만약 사람의 존재가 60초 동안 유지되는 평균 차이로 나타났다면, 그 차이는 이 단계에서 제거될 수 있다.** 모델은 남은 시간 변화로 두 상태를 구분해야 한다.

다만 위 표는 계산 원리를 설명한 예시다. 이번 실측 자료에 유용한 평균 차이가 있었고 그것만 살리면 구분된다는 사실을 확인한 것은 아니다.

이번 입력의 시간 변화가 과거 정지와 달랐고 저장 모델이 이를 빈 방으로 해석했다는 점에서, 학습 때 배운 구분 방식이 이번 환경에서도 잘 작동하지 않은 것으로 볼 근거가 있다. 이것을 원문에서는 **일반화 실패**라고 표현했다.

평균 빼기를 삭제하면 모델에 들어가는 값이 학습 때와 달라진다. 이 규칙을 바꾸려면 새로운 입력 규칙에 맞춰 학습하고 평가해야 한다.

## 4. 장비·수집·코드 문제인지도 확인했다

앞의 설명을 하기 전에, 입력 자체가 잘못됐거나 모델을 가져오면서 계산이 달라진 것은 아닌지 검사했다.

| 확인한 질문 | 확인 결과 | 해석 |
|---|---|---|
| 다른 수신기를 사용했나? | 기록상 RX 3대와 SINK 식별자가 일치했다 | 장치가 바뀌었다는 근거는 발견하지 못했다 |
| 이번에만 무선 수집했나? | 과거에도 SINK 업링크를 사용했다 | 이번에만 무선이라 생긴 문제로 설명할 근거가 없다 |
| 장치가 꺼졌거나 신호가 모두 0이었나? | 이번 정지 입력에서 그런 현상은 없었다 | 사람이 있어도 측정 자체가 멈춘 경우는 아니었다 |
| 데이터 누락이 앉기 오판을 만들었나? | 확인된 RX103의 긴 누락은 퇴실 뒤에 있었다 | 그 누락은 이번 앉기 오판의 원인이 아니다 |
| 가져온 모델이나 입력 계산이 달라졌나? | 검사한 코드와 입력 계산에서 불일치를 발견하지 못했다 | 가져오기·변환 오류로 설명할 근거는 찾지 못했다 |
| 과거에는 서 있는 사람만 배웠나? | 서기·의자 앉기·바닥 앉기가 학습 메모에 있었다 | 앉기 자료가 전혀 없었던 것은 아니다 |

이 확인은 모든 가능한 오류가 없다고 증명한 것은 아니다. 검사한 범위에서 오판을 설명할 다른 문제를 찾지 못했다는 뜻이다.

반면 **실제 방과 장치·사람 배치까지 같았는지는 확인할 수 없었다.** 과거 학습 메모의 장소는 6m×7m 방 안의 3m×3m 측정 구역이고, 이번은 사용자의 개인 방이다. 좌표 파일에 과거 값이 남아 있다고 실제 설치 위치도 같았다는 뜻은 아니다.

따라서 방 크기, 장치 위치, 앉은 위치·방향, 자세, 주변 환경 중 무엇이 시간 패턴 차이를 만들었는지는 아직 구분하지 못했다.

## 지금 확실히 말할 수 있는 것과 남은 질문

**확인한 것:** 이번 앉기 입력의 시간 패턴은 학습 정지와 달랐다. 시간 모양을 조작하면 변화 크기를 유지해도 모델의 판단이 바뀌었다. 현재 모델은 그 모양을 중요한 단서로 사용한다.

**남은 질문:** 왜 이번 방에서 그 패턴이 약했는가? 현재 위상 입력으로 새 방의 빈 방과 정지를 구분할 정보가 충분한가? 소량 추가 학습을 하면 다른 날에도 개선되는가?

이를 확인할 후속 작업은 [새 방 위상 모델 추가 학습 계획](../../../doc/plans/2026-10-12-phase60-room-finetuning.md)에 정리했다. 학습 자료에서 좋아지는지뿐 아니라, 따로 수집한 검증 자료와 다른 날 시험 자료에서 개선되는지 확인할 예정이다.
