# 9월 16·17일 데이터 확인과 최종 모델 평가

> 상태: **SUPPORTING ANALYSIS — 2026-10-01 전체 원본 확인·모델 평가·재검산 완료**
> 대상: 9/16의 7세션과 9/17의 8세션, 총 15세션

## 결론

**최종 저장 모델의 30초 구간 정확도는 234/280 = 83.57%, 세션 판정은
12/15 = 80.00%였다.** 움직임은 두 날짜 모두 맞혔지만, 빈 방과 정지 상태를
서로 헷갈렸다. 특히 9/16에서 가만히 있는 사람을 빈 방으로 판단한 문제가 확인됐다.
현재 모델의 실사용 안정성이 확보됐다고 판단하기 어렵다.

이번 결과는 9/19·20의 60세션으로 학습해 저장한 파일을 그대로 적용한 점수다.
평가 입력은 30초, 이동 간격은 15초다. 0.3초 간격의 실시간 평가는 아니다.

정답은 `session.json`에서 읽었고, 모든 폴더 이름과 일치했다.

|---|---:|---:|---:|---:|---:|
| 9/16 | 7 | 2 | 3 | 2 | 131/132 |

9/17의 원본 24파일과 세션 기록 8개는 [지난 확인](20260917-data-audit.md) 때와
해시가 모두 같았다. 이번 범위에서는 9/16의 7세션을 포함해 전체 15세션을 확인했다.
같은 원본 파일을 이름만 바꿔 중복 등록한 경우는 없었다.
최종 모델의 학습 60세션과 세션 키·원본 파일 해시도 겹치지 않았다.

## 수집 품질과 입력 호환성

- 45파일의 모든 프레임에서 CRC·헤더·수신기 ID 검사를 통과했다.
- 원본 프레임 수가 각 세션 기록의 수와 전부 일치했다.
- 모든 파일의 설정은 v4, 채널 11, rate 11, sig_len 47, raw_len 128로 모델과 일치했다.
- 기록된 수신기 ID 대응은 101→1, 102→3, 103→2였다.
- 수집 중 boot ID 변경과 송신 순번 `tx_seq` 역행은 없었다.
- 중복 송신 순번은 첫 기록을 사용했다. 기존 순번 검사 규칙이 단발 이상으로
  판정한 12개 기록은 정렬 계산에서 제외했다. 원본 CRC 오류는 없었으며,
  제거·모호한 후보의 상세 목록을 데이터 확인 JSON에 보존했다.
- 세 RX 공통 시간은 299.99~300.06초, 관측률은 92.85~99.09%였다.
- 짧은 내부 누락을 기존 규칙으로 보간한 뒤 280개 구간 모두 유한한
  `(300, 51, 3)` 입력으로 변환됐다. 최종 모델은 이 배열의 진폭 채널만 사용한다.

원본 128바이트는 64개 복소수 I/Q 값이다. 이 모델의 전처리는 그중 RX당
사용 가능한 51톤의 진폭을 정렬한 뒤 3개 간격으로 17톤을 고른다.
수신기 3대의 총 51신호를 각각 30초 상대 진폭으로 바꾸고 300시점으로 줄인다.
위상·정답·날짜·세션 번호·누락률은 모델 입력에 넣지 않았다.

### 사용하지 않은 구간

- **9/16 s31:** RX102의 공통 구간 시작 경계에 보간되지 않은 1프레임이 남아
  0~30초 구간을 제외했다. 첫 유효 구간은 **15~45초**다. 경계 밖 값으로
  채우지 않는 기존 규칙을 유지했다.
- **9/17 s44:** RX103의 6프레임 누락들이 5프레임 보간 한도를 넘었다.
  남은 미관측 18프레임을 포함한 180~210초, 195~225초 구간을 제외했다.
- **s36·s42:** 공통 길이가 29,999프레임으로 마지막 30초 구간이 완성되지 않아
  후보 자체가 18개였다. 후보를 만든 뒤 제외한 구간으로 세지는 않는다.

전체 후보 283개 중 제외한 것은 3개이며, 정확도의 분모는 판정한 280개다.
15세션 중 세션 전체가 제외된 경우는 없다.

## 상태별로 얼마나 맞혔나

가로줄은 실제 상태, 세로열은 모델이 판정한 상태다.

| 실제 상태 | 빈 방 판정 | 정지 판정 | 움직임 판정 | 실제 그 상태 중 맞힌 비율 |
|---|---:|---:|---:|---:|
| 빈 방 | 79 | 16 | 0 | 79/95 = 83.16% |
| 정지 | 30 | 64 | 0 | 64/94 = 68.09% |
| 움직임 | 0 | 0 | 91 | 91/91 = 100.00% |

마지막 열은 재현율이다. 정지 구간 94개 중 **30개를 빈 방으로 판단**했고,
빈 방 구간 95개 중 **16개를 정지로 판단**했다. 오류 46개는 모두 두 상태 사이에 있다.

정지를 맞힌 비율은 날짜 차이가 컸다. 9/16에서는 29/57 = **50.88%**,
9/17에서는 35/37 = **94.59%**였다. 세션 전체에서도 정지 5세션 중 3세션만
맞혔다. 움직임과 나머지를 나누는 데 비해, 사람의 정지 여부를 구분하는 힘이 약하다.
현재 파일만으로 이 차이를 특정 배치·호흡·환경 요인 때문이라고 확정할 수는 없다.

## 데이터 확인 방법

각 세션의 정답은 `session.json`을 기준으로 읽는다. 원본 CSI의 전체 CRC,
헤더·수신기 ID·RF 설정, 기록된 프레임 수, 재부팅·수신 누락, 세 RX의 공통
시간 구간과 관측률을 확인한다. 모델 입력으로 변환 가능한 30초 구간을 구한다.
원본 파일·세션 기록의 해시를 보존하고, 이전 9/17 확인 결과 및 최종 학습
자료와 비교한다. 데이터 구성과 날짜별 품질을 보고서에 기록한다.

## 평가 방법

9/19·20의 60세션으로 학습한 최종 모델 파일을 사용한다. 기존의 **30초 입력,
15초 이동 간격, 모델 3개의 확률 평균**을 고정하고 날짜별·전체 결과를 계산한다.
구간별 정확도, 모든 유효 구간을 모은 세션 판정, 첫 유효 30초 판정을 기록한다.
세션은 구간 수와 상관없이 한 번씩 집계한다. 모든 개별 모델 결과도 공개한다.

두 날짜를 함께 넣더라도 세션 키는 `날짜-s번호`로 구분한다. 학습 자료와의
세션 키·원본 파일 해시 중복을 검사하고, 앞서 확인한 유효 구간의 시작점과
평가에서 생성한 구간의 시작점을 대조한다. 저장한 확률로 지표를 재계산한다.
이전 9/17 결과는 별도 기록으로 유지하고 동일 자료의 결과가 재현되는지 확인한다.

## 데이터 사용 이력

[이전 파일럿 보고서](archive/cnn1d-pilot-cv-report.md)와 실행 코드에는 같은
9/16 s31~s37, 9/17 s38~s45를 후보 비교에 사용한 기록이 있다.
당시 실행 산출물이 없어 현재 파일과 당시 파일의 바이트 동일성은 미확인이다.
이번 결과는 최종 모델의 학습 자료 밖에서 하는 추가 평가이며, 프로젝트에서
한 번도 접하지 않은 자료를 사용한 시험으로 부르지는 않는다.

이번 스냅샷에는 명시적 `placement_id`와 배치 사진이 없다. 기존 파일럿 기록은
9/16 s31~s33을 A, s34~s37을 B, 9/17을 C·D·E로 분류했다.
s37을 TX-RX101 직선상 정지라고 적은 것도 이전 기록이다. 이번 원본만으로
그 위치를 다시 확인하거나, 9/19·20의 P1·P2·P3와 같은 배치라고 할 수는 없다.

## 검증과 산출물

- 최종 모델·감사 결과·학습 목록·원본 45파일·세션 기록 15개, 총 63파일의 해시 불변.
