# 여섯 상태 모델을 10월 13일 기록으로 비교하기

> 상태: **EXPERIMENTAL** — 2026-10-30. 모델 배포 변경 없이 수행하는 녹화 재생 비교.

## 고정한 범위

사용자 요청에 따라 10/6 기록은 사용하지 않는다(삼각대 없는 배치).
평가는 `20261013-223405-12476623` 한 기록만 사용한다.
진폭·위상 각각 15/30/60초를 9월 74세션(s12 제외)으로 새로 학습한다.
기존 파일럿과 같은 공통 유효 학습 시점·15 epoch·seed 0/1/2·학습 간격 15초를 유지한다.
현재 배포 중인 진폭 15초 가중치도 별도 기준으로 평가한다. 10월 자료는 학습하지 않는다.

모든 구성에서 현재의 진폭 3초 움직임 모델, 0.3초 간격, 상태 기계 기본값을 고정한다.
3초 모델 확률 0.9 이상 3회면 motion 후보를 우선하고, 확신 0.6·motion 1초·rest 5초·
empty↔static 직접 전환 10초를 사용한다. 상태 모델 입력이 유효하지 않으면 기존 엔진처럼
상태와 후보를 유지한다. 준비 시간에는 3초 모델만으로 상태를 확정하지 않는다.

## 정답과 재생 방법

실험 브랜치 `experiment/csi-phase-ablation`의 `20261013-room-live-evaluation.md`에
보존된 사용자 기록을 정답으로 고정한다. 모델 예측으로 정답을 바꾸지 않는다.

| 구간 | 정답 | 시작 | 끝 |
|---|---|---|---|
| 집 밖 1 | empty | 22:34:32 | 22:37:41 |
| 걷기 | motion | 22:37:57 | 22:41:00 |
| 침대 정지 | static | 22:41:03 | 22:44:04 |
| 중문 밖 정지 | static | 22:44:17 | 22:47:19 |
| 집 밖 2 | empty | 22:47:29 | 22:50:37 |

세 RX의 원본을 TX 순번으로 맞춰 매 30프레임마다 당시 도달 가능한 공통 끝점을 사용한다.
미래 프레임을 보간에 쓰지 않는다. 창 시작/끝이 누락이면 창 바깥 관측으로 보간하지 않는다.
실제 수신 호스트 시각은 프레임에 없으므로 이는 **100Hz 프레임 시계 기반 재생**이며
당시 USB flush·GUI 폴링 지연·실제 온라인 판단 정지를 완전히 재현한 시험은 아니다.
시간축은 매니페스트 시작 시각에 공통 첫 프레임을 대응한다. ±1초 민감도도 함께 본다.
당시 예측 로그의 wall/tx_seq 대응과 시간축 차이를 진단하되 라벨에 맞춰 이동시키지 않는다.

## 비교 지표

- 상태 모델 단독 argmax와 3초 모델+상태 기계 최종 표시를 따로 평가한다.
- 정답 구간 전체와, 모든 후보에 공통으로 각 구간 시작 후 60초를 뺀 결과를 모두 낸다.
- 전체 시간 일치율·판단 가능 시간 일치율·클래스별 일치율·판단 불가 시간을 기록한다.
- 상태 모델 새 예측 가능 비율을 별도 기록한다. 상태 기계가 예전 표시를 유지하는 것을
  새 추론 성공으로 세지 않는다.
- 첫 정답 표시까지와 10초 연속 정답 표시 시작까지를 기록한다. 기록된 행동 시작 기준이며
  문 여닫기·이동 구간은 정답이 없으므로 물리적 전환 지연의 정밀 측정이라고 하지 않는다.
- 한 녹화의 기존 자료 재비교로, 새 방 일반 성능·독립 최종 시험이라고 주장하지 않는다.
