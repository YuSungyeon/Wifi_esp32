# 9월 17일 데이터로 최종 저장 모델 평가

> 상태: **SUPPORTING ANALYSIS — 2026-10-01 최종 저장 모델 평가·재검산 완료**
> 대상: 9월 17일 8세션, 저장된 30초 상대 진폭 모델 3개의 확률 평균
> 후속 확인: [9월 16·17일 전체 15세션 평가](20260916-17-model-evaluation.md)를 완료했으며, 아래 9/17 결과는 그대로 재현됐다.

## 결론

**30초 구간은 149개 중 131개 정답(87.92%), 약 5분을 모은 세션 판정은
8개 중 7개 정답(87.50%)이었다.** 각 세션의 첫 30초도 7/8이었다.

움직임은 모두 맞혔다. 오류는 모두 빈 방과 정지 상태 사이에서 발생했다.
실제 빈 방인 s43을 세션 전체로도 정지라고 판단했다. 현재 모델은 이 자료에서
빈 방을 안정적으로 구분하지 못하는 구간이 있어, 실사용 안정성이 확보됐다고
판단하기 어렵다. 이번 평가는 최종 파일의 가중치를 고정한 실제 추가 평가다.

| 평가 단위 | 정답 수 | 정확도 | 세 상태의 평균 F1 |
|---|---:|---:|---:|
| 30초 구간 | 131/149 | 87.92% | 0.8718 |
| 약 5분 세션 전체 | 7/8 | 87.50% | 0.8667 |
| 각 세션의 첫 30초 | 7/8 | 87.50% | 0.8667 |

F1은 잘못된 판정과 놓친 판정을 함께 반영한 지표다. 평균 F1은 세 상태를
같은 비중으로 평균한다. 정확도는 전체 판정 중 정답의 비율이다.

## 어떤 상태를 헷갈렸나

아래 표는 30초 구간 149개의 결과다. 가로줄은 실제 정답, 세로열은 모델 판정이다.
예를 들어 빈 방 57개 중 41개는 빈 방, 16개는 정지로 판단했다.

| 실제 정답 | 빈 방으로 판정 | 정지로 판정 | 움직임으로 판정 | 해당 상태를 맞힌 비율 |
|---|---:|---:|---:|---:|
| 빈 방 | 41 | 16 | 0 | 41/57 = 71.93% |
| 정지 | 2 | 35 | 0 | 35/37 = 94.59% |
| 움직임 | 0 | 0 | 55 | 55/55 = 100.00% |

마지막 열은 **재현율**, 즉 실제로 그 상태였던 구간 중 맞힌 비율이다.
빈 방을 정지로 잘못 판단한 16개는 사람이 없는데 있다고 판단한 오류다.
이 수치를 실시간 시간당 오경보 횟수로 해석할 수는 없다. 구간이 서로 겹치고,
현재 평가는 고정된 상태로 수집한 세션을 대상으로 한다.

## s43은 구간 절반 이상을 맞혔는데 왜 세션은 틀렸나

s43의 19개 구간 중 빈 방 판정은 10개, 정지 판정은 9개였다. 하지만 현재
세션 판정은 투표 수가 아니라 **각 구간의 예측 확률을 평균**해서 정한다.

| s43의 전체 구간 평균 점수 | 빈 방 | 정지 | 움직임 |
|---|---:|---:|---:|
| 모델 3개의 확률 평균 | 45.14% | 47.62% | 7.24% |

정지 점수가 빈 방보다 2.48%p 높아서 정지로 판정했다. 예를 들어
195~225초 구간의 정지 점수는 86.61%, 225~255초는 85.09%였다.
이처럼 정지로 강하게 판단한 구간들이 평균에 영향을 줬다.
시간은 원본의 세 RX 공통 구간 시작점 기준이다. 점수는 확률 보정을 거친
신뢰도가 아니며, 정지 점수 47.62%가 정확도 47.62%라는 뜻도 아니다.

## 모델 3개를 각각 보면

저장 파일의 순서는 학습 seed 0·1·2 순서다. 모든 모델의 결과를 함께 기록한다.

| 모델 | 30초 구간 정답·정확도 | 세션 정답 | 첫 30초 정답 |
|---|---:|---:|---:|
| 모델 1 (seed 0) | 129/149 · 86.58% | 8/8 | 6/8 |
| 모델 2 (seed 1) | 132/149 · 88.59% | 7/8 | 7/8 |
| 모델 3 (seed 2) | 135/149 · 90.60% | 8/8 | 7/8 |
| 세 모델 확률 평균 — 고정된 최종 방식 | 131/149 · 87.92% | 7/8 | 7/8 |

s43의 빈 방/정지 점수는 모델 1이 46.93%/45.41%, 모델 2가
41.12%/50.82%, 모델 3이 47.37%/46.62%였다. 모델 1·3은 빈 방을
아주 근소하게 선택했고, 모델 2는 정지 쪽으로 더 기울었다. 확률 평균에서는
정지가 선택됐다. **모델 여러 개를 평균한다고 항상 개별 모델보다 좋은 것은 아니다.**

평가 결과를 보고 모델 하나를 고르거나 다수결로 바꾸지 않았다. 그런 변경을
비교하려면 이 8세션은 개발 자료가 되며, 변경 후 성능을 확인할 별도 자료가 필요하다.

## 평가 방법

9월 19·20일의 60세션으로 학습한 최종 파일을 그대로 읽어 평가한다.
모델 가중치·입력 전처리·30초 길이·15초 이동 간격·확률 평균 규칙을 고정한다.
정답은 각 세션의 `session.json`에서 읽고, 모델 입력에는 넣지 않는다.

원본 파일과 세션 기록의 해시를 앞선 [데이터 확인](20260917-data-audit.md)과
대조한다. 같은 세션 키나 원본 파일 해시가 최종 학습 목록에 있으면 평가를 중단한다.
예상 구간은 151개 중 유효 149개이며, 재생성한 시작점까지 기존 확인 결과와 대조한다.

구간별 판정은 세 모델의 예측 확률 평균에서 가장 큰 상태다. 세션 판정은 그
세션의 모든 유효 구간 확률을 다시 평균해 정한다. 첫 유효 30초 판정도 별도로
기록한다. 모델별 결과는 진단용으로 모두 공개하며 최고 모델만 골라 쓰지 않는다.

구간·세션·첫 구간의 정확도, 클래스별 재현율, 혼동 행렬과 평균 F1을 계산한다.
개별 구간 확률과 모델별 확률을 저장해 다시 집계할 수 있게 한다.

실행 코드: [저장 모델 평가](../../robust/evaluate_raw.py).
예측은 기존 [추론 코드](../../robust/predict.py)를 호출했다.
실행 전 절차와 코드 사본은 산출물의 `source/`에 보존했다.

- 재생성한 모든 유효 구간의 시작점·수량이 앞선 데이터 확인 결과와 일치.
- 세 모델을 각각 실행한 확률의 평균이 기존 앙상블 추론 결과와 일치.
- 저장한 확률에서 정확도·F1·혼동 행렬·재현율을 별도로 재계산해 일치.
- 모델 가중치와 BatchNorm 통계가 실행 전후 완전히 동일.
- 집계 회귀 테스트 2개와 기존 robust 테스트 13개, 총 15개 통과.

## 해석 범위

9월 17일은 최종 모델의 가중치 학습에 포함되지 않았다. 다만 같은 날짜·세션
번호를 사용한 과거 파일럿 기록이 있어, 프로젝트에서 한 번도 보지 않은 자료로
부르지는 않는다. 당시 파일과 현재 원본의 바이트 동일성은 미확인이다.
149개 구간은 서로 겹치며, 독립 수집 단위는 8세션이다. 세션 판정은 약 5분을
모은 결과이고, 상태 전환·실시간 판정 지연은 이번 평가 대상이 아니다.

이전 보고서의 9/19↔9/20 구간 정확도 97.31%/95.59%는 날짜별로 따로
학습한 평가용 모델의 점수다. 이번 87.92%는 60세션 전체로 학습한 최종 파일을
9/17 자료에 적용한 점수다. 모델과 자료가 달라 단순히 같은 시험의 점수 하락으로
보지는 않지만, 다른 수집 자료에서 빈 방 구분이 약해졌다는 문제는 확인됐다.
현장 배치·환경 차이의 구체적인 원인은 현재 기록만으로 확정할 수 없다.
