## 확인 결과

현재 폴더에는 약 5분짜리 세션 8개가 있다. `empty` 3개, `static` 2개,
`motion` 3개이며, 모든 세션에 RX101·RX102·RX103의 `.csi` 파일이 있다.
총 24파일, 120,225,248바이트(약 120.2 MB), 698,984프레임을 확인했다.

저장된 robust 최종 모델의 학습 세션 목록은 9/19·9/20의 60세션이다.
9/17의 세션 키는 이 목록에 없고, 24개 원본 파일의 SHA-256도 당시 학습 자료의
원본 180개 파일과 겹치지 않는다. 따라서 이 8세션은 **현재 robust 최종 모델의
학습 자료 밖에서 추가 평가할 수 있는 자료**다.

다만 [이전 파일럿 실험 보고서](archive/cnn1d-pilot-cv-report.md)와 실행 코드에
같은 날짜·세션 번호(s38~s45)를 후보 비교에 사용한 기록이 있다. 당시 실행 산출물이
남아 있지 않아, 지금 파일이 당시 파일과 바이트 단위로 같은지는 확인하지 못했다.
‘지금 robust 모델의 가중치 학습에 사용하지 않았다’와 ‘프로젝트에서 한 번도
분석하거나 후보 선택에 쓰지 않았다’는 다른 의미다. 이 사용 기록이 있는 만큼,
이번 자료를 완전히 처음 사용하는 독립 시험 자료라고 표현하지 않는다.

## 세션별 구성

라벨은 `session.json`을 기준으로 읽었으며 폴더 이름과 8세션 모두 일치한다.
메타 스냅샷의 `label_target`은 수집 시작의 기본값이므로 정답으로 사용하지 않았다.

| 세션 | 라벨 | 세 RX 공통 길이 | 30초 후보 구간 | 사용 가능한 구간 |
|---|---|---:|---:|---:|
| s38 | motion | 300.02초 | 19 | 19 |
| s39 | static | 300.00초 | 19 | 19 |
| s40 | empty | 300.02초 | 19 | 19 |
| s41 | motion | 300.01초 | 19 | 19 |
| s42 | static | 299.99초 | 18 | 18 |
| s43 | empty | 300.05초 | 19 | 19 |
| s44 | motion | 300.05초 | 19 | 17 |
| s45 | empty | 300.05초 | 19 | 19 |
| 합계 | 8세션 | 약 40분 | 151 | 149 |

현재 robust 입력 규칙의 30초 길이·15초 이동 간격을 그대로 적용했다.
상태별 유효 구간은 empty 57개, static 37개, motion 55개다.
이 구간들은 겹치므로 독립 수집 149번을 뜻하지 않는다.

s42는 공통 길이가 30,000프레임보다 한 프레임 짧아 마지막 후보가 만들어지지
않았고 18개가 남았다. s44는 RX103에 짧은 보간 기준(최대 5프레임)을 넘는
6프레임 누락들이 있어 보간되지 않은 위치 18개가 남았다. 이 위치를 포함하는
30초 구간 2개를 제외했다.

## 수집 품질과 모델 입력 호환성

- 24파일의 전체 프레임 CRC·헤더·수신기 ID를 검사했고 오류가 없었다.
- 원본 프레임 수는 `session.json`의 수와 모두 일치했다.
- 모든 파일이 v4, 채널 11, rate 11, sig_len 47, raw_len 128로 현재 모델의
  원본 입력 조건과 일치했다. 장치별 기록 ID는 101→1, 102→3, 103→2였다.
- 모든 RX에서 수집 도중 boot ID 변경과 `tx_seq` 역행은 없었다.
  중복된 `tx_seq`는 있었으며 정렬 시 같은 순번의 첫 기록을 사용했다.
- 세 RX를 `tx_seq`로 정렬한 공통 길이는 299.99~300.05초였다.
  관측률은 92.85~99.09%로 기준 85% 이상을 모두 만족했다.
- 짧은 내부 누락을 기존 규칙대로 보간한 뒤, 유효 구간 149개를
  `amplitude_input()`으로 변환했다. 모두 `(300, 51, 3)` 형식과 유한한 값 조건을
  만족했다. 최종 A 모델은 이 배열의 진폭 채널 하나만 읽는다.

이 결과는 파일 품질과 입력 생성 가능 여부다. 이 데이터 확인 단계에서는
예측 정확도를 계산하지 않았으며, 후속 평가 수치는 위의 별도 보고서에 있다.

## 배치·환경 기록과 이전 사용 이력

8세션의 메타 스냅샷에는 명시적인 `placement_id`가 없고, 세션 폴더 안에 배치
사진도 없었다. 따라서 실제 위치나 환경 차이를 이 파일들만으로 확정할 수 없다.

이전 파일럿 보고서와 `cv_pilot.py`는 s38·s39·s40을 C, s41·s42·s43을 D,
s44·s45를 E로 묶었다. 당시 C·D는 번갈아 평가에 사용했고, static이 없는 E는
항상 학습에 사용했다. 이것은 이전 실험의 구분이며 9/19·9/20의 P1·P2·P3와
같은 배치라는 뜻은 아니다.
