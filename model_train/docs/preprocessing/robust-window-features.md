# 긴 윈도·결측 허용 시간 특징

> 상태: **EXPERIMENTAL — 구현·실측 검증 완료, 2026-09-24**

입력은 이전 phase51 실험의 검증된 `(T,459)` 캐시다. RX 101/102/103의 각 51톤
진폭, 보정 위상 sin, cos 순서이며 raw 인덱스는 `[38..63,2..26]`이다. 새 실험은
공식 192차원 모델과 별도 경로다. 캐시 hash와 세션 manifest를 검사한다.

100Hz `tx_seq` 격자에서 3/5/10/20/30초 구간을 만든다. 진폭의 미보간 결측이 있는
윈도는 제외한다. 기존 5프레임 이하 보간은 재사용하며 더 긴 gap을 채우지 않는다.

위상은 모든 프레임이 유효할 필요 없이 RX별 원래 유효 프레임이 80% 이상이면
사용한다. 0.1초 bin의 유효 샘플이 절반 이상인 경우 sin/cos 평균으로 원형 평균을
구한다. bin 간 미관측 값은 시간 평균 중심화 후 0으로 처리한다. 유효률/마스크는
모델 특징으로 넣지 않으며 제외량을 클래스·날짜별로 기록한다. 이 규칙은 분류
성능을 보기 전에 고정한다. 위상 원형 평균 길이는 미세 변동 통계로 사용한다.

진폭은 윈도별 톤 평균으로 나눈 상대 변동과 프레임별 RX 평균으로 나눈 형상
변동을 구분한다. 위상은 윈도 원형 평균을 기준으로 한 sin/cos 변화다. 시간 통계,
0.1~0.5/0.5~1/1~2/2~5Hz 대역, 단기 차분과 자기상관을 톤별로 계산하고, 톤·RX
풀링으로 배치 의존도를 줄인다. 대조군만 평균 진폭 프로파일을 사용한다.

정규화·특징 선택·모델 적합은 학습 fold 안에서만 한다. 윈도 내부 평균은 해당
윈도 CSI만 사용하므로, 배치 전체·미래 세션·정답을 필요로 하지 않는다. 긴 윈도는
그 길이만큼 관측이 필요하며 실시간 지연과 5분 세션 평균 성능을 구분한다.

## 선택된 공유 인코더의 추론

최종 30초 A 모델은 진폭만 사용한다. 각 RX에서 51톤 중 3개 간격으로 17톤을
택하고, `A / (윈도 시간 평균 + 0.5)`를 10프레임 평균한 뒤 윈도 안에서 중심화한다.
여기에 3을 곱하고 ±20으로 제한한다. 학습과 추론의 진폭 입력이 정확히 일치함을
1,124개 윈도에서 재검증했다. 최종 30초 캐시에서 위상 gate 추가 제외는 0개였다.

`predict.py --features`는 정렬된 진폭 153차원 또는 phase51 459차원 배열을 받고,
후자의 위상 값은 A 모델에서 사용하지 않는다. `--session-dir`은 원본 v4 파일의
CRC·RF 조건·RX 식별을 검사한 뒤 같은 진폭 정렬을 재현한다. manifest의 라벨은
추론에 사용하지 않는다. 이 어댑터는 기존 27,000프레임 공통 구간 gate를 유지하는
완료된 수집 세션용이며, 스트리밍 버퍼 구현은 포함하지 않는다.
