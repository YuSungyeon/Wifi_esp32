# 모델 학습 문서

> 상태: 전처리와 공식 3-RX LSTM 코드는 **IMPLEMENTED**, 모델 비교 실험은 **PLANNED**

어떤 모델을 시도할지에 대한 후보 비교·선정 근거는
[학습 모델 비교와 선정 권고](%5B모델%5D-비교와%20선정.md) (**PLANNED**)를 먼저 본다.

코드와 문서를 분리한다. 실행 코드는 모델별 디렉터리에 두고, 전처리·모델 설계·
학습 문서는 이 `docs/` 디렉터리에 모은다.

```text
model_train/
├── docs/                              전처리·모델 설계·학습 문서
│   ├── [문서]-목록.md
│   ├── [전처리]-설계.md
│   ├── [전처리]-시퀀스 분석.md
│   ├── [전처리]-매니페스트 필드.md
│   ├── [전처리]-현재 구현.md
│   ├── [모델]-비교와 선정.md
│   └── [모델]-장단기메모리 설계와 학습.md
├── preprocessing/                      공통 3-RX 전처리 코드
│   └── preprocess_3rx.py
└── lstm/                               LSTM 실행 코드
    └── LSTM.py
```

## 읽는 순서

| 순서 | 문서 | 목적 |
|---:|---|---|
| 1 | [공식 전처리 설계](%5B전처리%5D-설계.md) | 모든 학습 모델이 공유하는 전처리 규칙과 완료 조건 |
| 2 | [`seq`·`tx_seq` 분석](%5B전처리%5D-시퀀스%20분석.md) | 전처리 판단 근거와 실데이터 집계 |
| 3 | [`manifest.json` 필드 설명](%5B전처리%5D-매니페스트%20필드.md) | 전처리 설정·품질·split·normalization 필드 해석 |
| 4 | [학습 모델 비교](%5B모델%5D-비교와%20선정.md) | 학습 모델 후보와 비교 계획 |
| 5 | [LSTM 모델 설계와 학습](%5B모델%5D-장단기메모리%20설계와%20학습.md) | 공식 3-RX 입력을 사용하는 LSTM 구조·학습·평가 방법 |
| 6 | [구형 전처리 구현 참고](%5B전처리%5D-현재%20구현.md) | 사용하지 않는 `Preprocessing.py`와 공식 전처리의 차이 확인 |

파일명은 `[카테고리]-내용.md` 형식을 사용한다. 전처리 규칙의 기준 문서는
`[전처리]-설계.md`이며 특정 모델에 종속되지 않는다. 모델별 문서는 공식
전처리가 만든 공통 산출물을 입력으로 사용한다.

공식 LSTM 실행법과 생성 파일은 5번 문서를 기준으로 한다. 구형
`Preprocessing.py`는 공식 LSTM 학습 경로에서 import하거나 실행하지 않는다.
