# MeshSense 소개 영상

소프트웨어과 졸업발표회에서 틀 프로젝트 설명 영상이다. 원리 → 장치·수집 → 학습 데이터 → 모델 안 →
실시간 판단·성능 → 서비스 → 한계 순서로 프로젝트 전체를 보여 준다.
1920×1080 · 30fps · 한국어 자막. 정지 장면은 `scenes.html`, 모션그래픽은 `motion.html` 에 있고,
`build.py` 가 둘을 찍어 CapCut 초안을 만든다.

| 버전 | CapCut 프로젝트 | 길이 | 내용 | 그림 위치 |
|---|---|---|---|---|
| v1 | `MeshSense_소개` | 55.5초 | 원리 → 수집 → 두 모델 → 서비스, 정지 장면 12개 | `out/v1/` |
| v2 | `MeshSense_소개_v2` | 76.5초 | v1 + 모션그래픽 21초 | `out/` 바로 아래 |
| v3 | `MeshSense_소개_v3` | 4분 4초 | 7개 파트로 최대한 자세히 | `out/v3/` |
| v4 | `MeshSense_소개_v4` | 4분 39.5초 | v3 를 검토 둘(기술 전문가 · 영상 편집자)로 고친 판 | `out/v4/` |
| **v5** | **`MeshSense_소개_v5`** | **4분 33초** | **v4 에서 약점 표현을 덜고 화면을 짚어 고친 판 — 지금 `build.py` 가 만드는 것** | `out/v5/` |

v1~v4 는 고정본이다. `build.py` 는 v5 만 다시 만들고 `out/v5/` 에만 쓴다.

## v4 → v5 에서 바뀐 것

v4 가 약점을 너무 드러냈고 불필요한 곳이 있다는 판단으로 화면을 하나씩 짚어 고쳤다.
전후 비교는 `out/v5_preview/compare.html`, 한계 장면(30·31)을 다시 고친 것은 `out/v5_preview/limits/compare.html`.

- **왜 카메라 대신 Wi-Fi 인가** — 카메라의 문제를 "부담스럽다" → **영상이 유출되면 사생활이 드러난다** (화면 · 자막)
- **정지는 빈 방과 거의 같다** — 흔들림 숫자를 6초 한 구간 → **9/16·17 세션 15개 × RX 3대 평균**(빈 방 0.75 · 정지 0.77 · 움직임 2.00).
  그래프는 각 상태에서 그 평균에 가장 가까운 6초. v4 는 숫자는 같았지만(0.71 · 0.70) 정지 그래프에 한 프레임짜리 튐이 몰려 더 떨려 보였다
- **프레임 172바이트** — "머리말" → **헤더**, 매직(0x4353)·버전(4)을 막대 맨 앞과 첫 카드로 따로 보임, 카드 설명의 " — " 를 줄바꿈으로
- **무선** — "수신률도 단서 · 가설" → **"단서 후보 — 무선이라 이 값도 함께 남는다"** (모델 입력은 지금 진폭뿐)
- **번호표로 맞추기** — "앞뒤를 이어 메운다" → **"앞뒤 값을 직선으로 이어 메운다 (선형 보간)"**
- **학습에 안 쓴 날로 시험** — 다른 날·배치 행(12/15 · 77.3%)을 뺀다
- **얼마나 빨리, 얼마나 맞나** — 장면을 통째로 뺀다 (81.7% · 전환 지연). 시험 장면 다음에 바로 '신호가 끊기면 멈춘다' 로 간다
- **조명 규칙 · 알림** — 규칙과 시간은 사용자가 정하고 화면 값은 예시임을 밝힌다. 빨간 "시연용 — 안전 장치를 대신하지 않는다" 는 뺀다
- **한계** — "아직 모르는 것" → **"한계와 다음 단계"**(파트 표지 부제 · 전체 지도도). 카드는 셋 — **공간은 두 곳**(오래 빌려 시험할 수 있던 곳은
  자취방 · 향설 2층 활동실뿐) · **하루 넘게는 아직**(자취방에서 1~2시간 연속은 했지만 24시간 넘게는 못 함) · **다양한 자세**(누운 자세는 시연에서
  인식했지만 학습 데이터엔 없음, 다른 정지 자세도 학습 전). 자막을 셋으로 나눠 9초 → 10.5초. "날·배치가 바뀌면 흔들린다" · 반려동물 · "가장 긴 연속 실행 9분" 은 뺀다
- **다음 단계** — 한계와 맞춘다: "다른 방 · 다른 보드 배치" → "다른 공간 · 다양한 자세", "몇 시간씩 켜 두고" → "하루 넘게 켜 두고"

## v3 → v4 에서 바뀐 것

검토자 셋(기술 전문가 · 완전 비전문가 · 영상 편집자) 중 **발표 대상이 소프트웨어과라 비전문가 의견은 뺐다.**
그래서 CNN · CRC · UDP 같은 용어와 프레임 구조 장면은 살렸다.

**사실 정정 (기술 전문가)**
- 81.7% · 전환 지연 — "학습에 쓴 날짜의 녹화를 이어 붙인 대본으로 잰 값 · 처음 보는 날·실제 전환은 아직" 을 화면과 자막에 밝힌다
- 서비스 — "시연용 — 안전 장치를 대신하지 않는다", 한계에 "누운 자세 · 반려동물은 시험 전" 을 더한다
- CSI 막대를 원래 번호 순서([1..26, 38..63])가 아니라 **주파수 순서**([38..63, 1..26])로 다시 그린다
- "신호의 세기만 남는다" → "모습 대신 전파 측정값(CSI)만 남는다" (`.csi` 에는 위상·RSSI 도 있다)
- 3초 모델 성적에 "움직임 / 아님 2가지" 를 붙이고, "날이 바뀌면" → "날·배치가 바뀌면"
- 진폭·위상 장면에 "위상은 보드마다 시계가 달라 매번 틀어진다" 를 더한다
- 모션그래픽 "0.3초마다 한 칸씩" → "0.3초(30프레임)마다" (150칸의 '칸'과 뜻이 겹쳐서)
- 무선 장면의 "수신률도 단서" 는 **가설**로 표시하고 "아직 모델에는 쓰지 않는다" 를 붙인다

**보기 편하게 (영상 편집자)**
- 모션그래픽 21초 → 35초. 전처리 4단계 → 2단계
- 자막은 한 줄 24자 안팎 · 두 줄까지. 길면 `||` 로 나눠 차례로 띄운다 (자막 35개 → 58개)
- 상태 색(회색 · 파랑 · 주황)은 세 상태에만 쓴다 — 15초 모델 보라 · 3초 모델 분홍 · 싱크 밝은 회색 · 경고 빨강
- 왼쪽 위 번호 01~31 을 없애고 **PART N** 으로 — 파트 표지와 어긋나지 않는다
- 용어 통일 — "수신 보드 101" → "RX 101", "가족" → "지인", "마지막 판단 정지" → "마지막 판단 · 정지 상태"
- 시작을 **같은 방이 빈 방(불 꺼짐) → 움직임(불 켜짐)** 으로 바뀌는 장면으로, 끝을 같은 방 위의 맺는 카드로
- 겹치던 장면을 뺀다 — "이 모델로 만들 수 있는 서비스" 요약 장면(뒤 장면들이 다시 말한다), 맨 앞의 '판단 중' 카드
- "학습에 안 쓴 날로 시험한다" 를 PART 5 로 옮긴다 — 15초·3초 모델을 소개한 뒤에 나와야 읽힌다
- 빽빽한 장면은 글을 줄이고 길이를 늘린다 (프레임 · 무선 · 상태 기계 · 알림 · 한계)

**받아들이지 않은 것**
- 길이 줄이기(7파트 → 4막, 3분 30초) — 길이는 신경 쓰지 않기로 해서 빽빽한 곳을 늘리는 쪽을 택했다
- 기술 보강(312.5kHz 간격 · 가중치 4,814개 · 수신률 93~99%) — 화면이 다시 빽빽해진다. 발표에서 말로 보탠다

## CapCut 에서 열기

CapCut 홈의 프로젝트 목록에서 **`MeshSense_소개_v5`** 를 연다. v1~v4 는 그대로 있다.

- **배경 음악**: 오디오 → 음악에서 5분 남짓을 깔고 끝 1초 페이드 아웃
- **내레이션**: 자막을 선택 → 텍스트 읽기(TTS). TTS 를 넣으면 장면 길이를 TTS 에 맞춰 다시 잡는다(편집자 권고)
- **만든 사람**: 맺는 장면(`scenes.html` `s34`)에 팀·지도교수·저장소 주소를 넣으면 된다 — 지금은 "소프트웨어과 졸업 작품" 만 있다

## 다시 만들기

장면 순서·길이·자막은 `build.py` 의 `SCENES`, 정지 그림은 `scenes.html`, 모션그래픽은 `motion.html` 에서 고친다.

```bash
python3 -m venv ~/.capvenv && ~/.capvenv/bin/pip install pycapcut==0.0.4 playwright imageio-ffmpeg
~/.capvenv/bin/python design/intro-video/build.py
```

- 정지 장면은 Chrome(헤드리스)으로 `scenes.html?s=N&no=PART%20N` 을 찍어 `out/v5/scene_N.png` 로 만든다.
- 모션그래픽은 설치된 Chrome 을 Playwright 로 띄워 `motion.html` 의 `render(t)` 를 30fps 로 한 장씩 찍고,
  imageio-ffmpeg 에 들어 있는 ffmpeg 로 `out/v5/motion.mp4`(H.264) 로 묶는다. 전체 빌드 약 1분.
- `SCENES` 의 `"m"` 줄 길이가 `motion.html?beats=` 로 넘어가 애니메이션 구간이 된다.
- 자막에 `||` 를 넣으면 그 장면 길이를 똑같이 나눠 차례로 띄운다.
- 브라우저에서 `scenes.html?s=ch3`, `scenes.html?s=24`, `motion.html?play` 처럼 열어 볼 수 있다.
- 같은 이름의 CapCut 초안을 **덮어쓴다**. CapCut 에서 손본 게 있으면 먼저 CapCut 안에서 복제해 둔다.
- **CapCut 에서 프로젝트를 열어 둔 채 돌리지 않는다** — 열려 있으면 폴더에 `.locked` 가 있고, CapCut 이 저장하며 덮어쓴다.
- 초안은 `out/v5/` 의 파일을 절대 경로로 가리킨다 — 지우거나 옮기면 CapCut 에서 미디어가 빠진다.
- `--no-draft` 를 붙이면 PNG · mp4 · SRT 만 만든다.
