# 새 방에 맞춘 위상 모델 추가 학습 작업 목록

> 상태: **PLANNED** — 2026-10-12 계획 작성. 아래 수집·학습·시험은 아직 실행하지 않았다.
> 목표: 기존 위상 60초 모델에 내 방 자료를 조금 추가로 학습시켜 빈 방과 앉아 있는 사람을 더 잘 구분하는지 확인한다.

## 무엇을 하려는가

처음부터 새 모델을 만드는 것이 아니다. **기존 60세션으로 학습한 모델에서 시작해, 새 방 자료로 일부 가중치를 조정한다.** 이것을 파인튜닝이라고 한다.

성공 여부는 학습 자료가 아니라 **추가 학습에 쓰지 않은 다른 날의 자료**로 판단한다. 우선 같은 방·장치 배치·의자 위치에서의 개선이 목표다. 다른 방이나 모든 자세에서도 좋아진다고 주장하지 않는다.

10/6 원본의 위상 재생에서 앉기 구간 정지 일치율은 0%였다. [원인 분석](../../model_train/docs/model-training/20261008-phase60-static-diagnosis.md)에서는 학습 자료와 이번 자료의 시간 패턴 차이를 확인했다. 방 변화가 유일한 원인이라고 확정한 것은 아니다. 현재 위상 입력에 두 상태를 구분할 정보가 충분한지도 이번 시험으로 확인해야 한다.

## 전체 진행표

| 번호 | 할 일 | 완료 기준 | 상태 |
|---:|---|---|---|
| 1 | 수집 조건·자료 분리 확정 | 배치, 정답 기록법, 학습/검증/시험 목록 확정 | 미실행 |
| 2 | 새 방 자료 수집·검사 | 세 상태의 유효 자료와 정답 시각 확보 | 미실행 |
| 3 | 추가 학습 코드 준비 | 기존 예측 재현, 자료 분리·가중치 동결 검사 통과 | 미실행 |
| 4 | 일부 가중치 추가 학습 | 검증 자료로 후보 하나 선택 | 미실행 |
| 5 | 다른 날 자료로 최종 비교 | 기존/적응 모델의 같은 자료 비교 완료 | 미실행 |
| 6 | 실제 전환 시험·결론 | 오판·반응 지연을 기록하고 채택 여부 판단 | 미실행 |

한 단계씩 실행하고 결과를 이 문서에 기록한다.

## 1번 — 수집 조건과 자료 분리 확정

- [ ] TX·RX 3대·SINK의 위치, 높이, 방향을 사진과 메모로 남긴다.
- [ ] 의자 위치·앉는 방향·걷는 범위를 정한다. 첫 시험은 한 의자 위치로 제한한다.
- [ ] 문, 선풍기·에어컨, 주변 사람 유무를 기록한다. 빈 방과 정지는 가능한 한 같은 조건으로 수집한다.
- [ ] 정지는 앉아서 큰 동작 없이 있는 상태로 정한다. 숨을 참을 필요는 없다.

### 첫 소규모 시험의 수집 제안

한 번의 녹화에서 **빈 방 3분 → 걷기 3분 → 앉아서 정지 3분**을 기록한다. 이동·착석 시간은 별도다. 각 3분은 실제로 해당 상태가 시작된 뒤 센다.

| 용도 | 별도 녹화 횟수 | 각 상태 합계 | 안정 상태 총시간 | 사용 방법 |
|---|---:|---:|---:|---|
| 추가 학습 | 2회 | 각각 6분 | 18분 | 가중치 조정 |
| 검증 | 1회 | 각각 3분 | 9분 | 학습 중단·후보 선택 |
| 최종 시험 | 다른 날 2회 | 각각 6분 | 18분 | 선택 완료 후 최종 비교 |
| 합계 | 5회 | 각각 15분 | 45분 | 준비·이동 시간 별도 |

빈 방·정지의 **추가 학습 자료 자체는 합계 12분**이다. 나머지는 걷기 능력 유지와 개선 확인을 위한 자료다. 이 양은 첫 시도용 제안이며, 충분한 성능을 보장하는 최소량이 아니다. 독립 녹화 수가 적다는 한계도 보고한다.

- [ ] 녹화 전체를 학습/검증/시험 중 하나에 미리 배정한다. 같은 녹화의 창을 양쪽으로 나누지 않는다.
- [ ] 각 녹화는 수집을 종료한 뒤 새로 시작한다. 검증도 별도 녹화, 최종 시험은 다른 날로 분리한다.
- [ ] 후보 선택 전 시험 예측 결과를 보지 않는다. 원본 품질 확인과 시험 점수 확인은 구분한다.
- [ ] 5번의 채택 기준을 수집 전에 확정한다. 변경 시 이유와 시점을 남긴다.

예를 들어 같은 녹화의 0~60초를 학습에, 3~63초를 시험에 넣으면 거의 같은 신호를 이미 본 것이다. **겹치는 창을 무작위로 섞어 분리하지 않는다.**

## 2번 — 혼자 수집하고 정답 시각 기록하기

- [ ] 녹화를 시작하고 방을 나간 시각을 기록한다. 방 밖에서 빈 방 3분을 유지한다.
- [ ] 들어와 걷기 시작한 시각을 기록하고 3분간 걷는다.
- [ ] 앉기 시작한 시각과 **앉아서 안정된 시각**을 따로 기록한다. 안정된 뒤 3분을 유지한다.
- [ ] 일어나 녹화를 종료한다. 종료 버튼을 누르러 움직인 구간은 정지 정답에서 제외한다.
- [ ] 휴대전화 시계 등으로 실제 행동 시각을 기록하고 컴퓨터 시계와 차이를 확인한다. 모델 예측을 정답으로 쓰지 않는다.
- [ ] RX 3대의 원본 I/Q, 수집 메타데이터, 정답 구간표, 배치 사진을 보관한다.

정답 구간표에는 `녹화 ID / 용도 / 상태 / 안정 상태 시작 / 종료 / 불확실 구간 / 메모`를 적는다. 단일 상태 세션의 정답 기준은 기존 `session.json`을 유지한다. 여러 상태가 섞인 실시간 녹화에는 한 라벨을 억지로 붙이지 않고, 원본 ID와 연결된 별도 구간표를 사용한다. 구간표의 버전·해시도 남긴다.

- [ ] CRC·장치 식별·공통 송신 순번·누락·재부팅·순번 역행을 검사한다.
- [ ] **입력 60초 전체가 한 안정 상태 안에 포함되는 창만** 학습·정적 평가에 사용한다.
- [ ] 상태 변경 직후에는 이전 상태가 입력에 섞인다. 이런 창은 정적 평가에서 분리하고, 전환 반응은 6번에서 측정한다.
- [ ] 허용치를 넘는 누락 창은 제외 사유와 개수를 기록한다. 오답이라는 이유로 제외하지 않는다.

기존 위상 오프라인 로더는 공통 27,000프레임 이상을 요구한다. 따라서 **3분 구간을 기존 학습 명령에 바로 넣지 않는다.** 3번에서 별도의 구간 기반 입력 경로를 만들고 검사한다. 기존 길이 검사를 조용히 낮추지 않는다.

## 3번 — 추가 학습 코드와 비교 기준 준비

### 유지할 규칙

- 출발점은 `model_train/phase60/model_60sessions.pt`다. 9/19·20의 60세션 학습 모델을 사용한다.
- RX 3대 × 52개 위상 신호, 60초 6,000프레임을 300시점으로 만드는 기존 입력 변환을 유지한다.
- 출력은 `empty / static / motion`이다. 2분류로 바꾸지 않는다.
- seed 0·1·2의 모델을 각각 추가 학습하고, 최종적으로 클래스별 확률을 평균한다.
- 진폭 모델과 기존 위상 모델을 보존한다. 적응 모델은 별도 경로에 저장한다.

### 구현할 것

- [ ] 별도 파인튜닝 진입점을 만든다. 기존 `phase60/train.py`는 처음부터 새 모델을 학습하므로 그대로 실행하고 파인튜닝이라고 부르지 않는다.
- [ ] 각 seed에 대응하는 기존 가중치를 불러온다. 출발 모델 해시를 기록한다.
- [ ] 명시적인 원본·정답 구간·분할 목록으로 자료를 읽는다. 폴더 이름만으로 정답을 추정하지 않는다.
- [ ] 60초 구간 변환과 예측이 기존 위상 경로와 일치하는지 검사한다. 캐시는 원본·구간·전처리 버전을 구분한다.
- [ ] 동일 녹화, 중복 원본, 겹치는 구간이 다른 분할에 섞이지 않는지 검사한다.
- [ ] 기존 모델의 학습/검증 자료 예측을 기준값으로 저장한다. 시험 예측은 5번까지 보류한다.
- [ ] 설정·선택 기준·중단 조건·출력 경로를 실행 기록에 저장한다.

오프라인 학습·비교의 초기 이동 간격은 **3초**로 고정한다. 실시간의 **0.3초 이동**과 구분한다. 겹치는 창이 많아져도 독립 녹화 수가 늘지는 않으므로 녹화별 결과를 함께 낸다.

## 4번 — 작은 변경부터 추가 학습하기

### 후보 A: 마지막 분류 부분만 학습

CNN은 신호에서 특징을 뽑는다. 우선 CNN은 그대로 두고, 그 특징을 보고 세 상태 중 하나를 고르는 **마지막 분류 부분만 조정**한다.

- [ ] `encoders`를 고정하고 `head`의 두 Linear 층(128→64→3)만 학습한다.
- [ ] CNN의 BatchNorm도 평가 모드로 고정한다. 가중치만 고정하면 내부 평균·분산이 바뀔 수 있으므로, 학습 전후 통계까지 검사한다.
- [ ] 기존 60세션 자료와 새 방 자료를 섞는다. 초기에는 두 출처를 같은 비중으로 뽑고, 각 출처 안에서도 세 클래스 비중을 맞춘다.
- [ ] 새 방 걷기도 포함하고 검증한다. 빈 방·정지 개선 때문에 움직임 구분 능력을 잃지 않게 한다.
- [ ] 초기 설정은 학습률 `1e-4`, 최대 20 epoch, 검증 점수가 5 epoch 동안 개선되지 않으면 중단이다. 실제 실행 설정을 기록한다.

### 후보 B: A가 부족할 때만 CNN 마지막 부분도 학습

- [ ] A가 검증에서 부족할 때만 마지막 Conv 층과 head를 함께 조정한다.
- [ ] 앞쪽 CNN과 BatchNorm의 가중치·통계는 고정한다. 마지막 Conv 학습률은 `1e-5`, head는 `1e-4`로 시작한다.
- [ ] 입력 변환이나 전체 구조까지 한꺼번에 바꾸지 않는다.

검증에서 클래스별 정답률을 구하고 세 값을 동등하게 평균한 점수로 중단 시점과 후보를 고른다. 빈 방·정지 개별 점수와 움직임 하락도 확인한다. 세 seed를 포함한 앙상블 후보 하나를 선택하며, 시험 결과를 보고 seed를 빼지 않는다.

학습 자료에서만 좋아지고 검증에서는 좋아지지 않으면 **자료를 외웠을 가능성**이 있다. 수집 다양성·라벨·특징의 구분 가능성을 점검하며, 바로 기본 모델로 바꾸지 않는다.

## 5번 — 다른 날 자료로 최종 비교

- [ ] 선택한 모델·설정·가중치 해시를 고정한다.
- [ ] 기존 위상 모델과 적응 모델에 **똑같은 시험 창**을 넣는다.
- [ ] 클래스별 정답률, 혼동표, 녹화별 점수를 저장한다. 정지→빈 방과 빈 방→사람 있음 오류를 따로 집계한다.
- [ ] 유효 창 점수뿐 아니라 전체 후보 수·판단 불가 수·제외 이유도 보고한다.
- [ ] 기존 9/16·17의 15세션에서도 성능 유지 여부를 확인한다. 이미 여러 번 본 자료이므로 새로운 독립 시험이라고 부르지 않는다.

### 채택 기준 제안

아래는 통계적 보장이 아니라 **결과를 본 뒤 기준을 바꾸지 않기 위한 초기 운영 기준**이다. 1번에서 확정한다.

- 새 방 시험의 빈 방·정지 정답률 평균이 기존보다 **10%p 이상 개선**될 것.
- 빈 방과 움직임 정답률은 각각 기존보다 **5%p 넘게 떨어지지 않을 것**.
- 두 시험 녹화 각각에서 빈 방·정지 정답률 평균이 나빠지지 않을 것.
- 기존 15세션의 세 클래스 평균 정답률이 **5%p 넘게 하락하면 보류**하고 기존 환경 성능 저하를 기록할 것.

통과해도 안정적인 범용 모델이라고 결론 내리지 않는다. 우선 이 배치에서의 실시간 시험 후보로 채택한다. 시험 결과를 보고 다시 학습 설정을 바꿨다면, 다음 최종 판단에는 **새 시험 녹화**가 필요하다. 10/6 자료도 이미 원인 분석에 썼으므로 새 독립 시험으로 재사용하지 않는다.

## 6번 — 실제 전환 시험과 결과 정리

- [ ] 적응 모델의 세 클래스·세 seed·입력 규격과 기존 로더 호환성을 검사한다.
- [ ] CLI의 사용자 모델 경로로 먼저 연결한다. GUI에서 적응 모델을 고르게 하려면 별도 선택 항목을 구현한다. 현재 위상 선택이 적응 모델을 자동으로 선택하는 것은 아니다.
- [ ] 새 녹화에서 빈 방 3분 → 걷기 2분 → 앉기 3분 → 걷기 2분 → 빈 방 3분을 수행한다.
- [ ] 초기 60초 준비와 기본 0.3초 이동을 유지한다. 이는 행동이 바뀐 뒤 0.3초 안에 맞힌다는 뜻은 아니다.
- [ ] 입실·완전히 앉음·다시 걷기·퇴실 시각, 첫 정답 표시, 다시 오판한 구간, 판단 불가 시간을 기록한다.
- [ ] 같은 원본을 기존 모델로도 재생해 비교한다. 재생 지연과 실제 운영 지연은 구분한다.
- [ ] 채택·추가 수집·보류 중 하나로 결론 내리고 기존 모델로 돌아가는 방법을 남긴다.

다른 의자 위치·다른 사람·장치 배치 변경은 후속 시험이다. 이번 한 위치 결과로 대신하지 않는다.

## 산출물과 결과 기록

- 수집 조건·배치 사진·정답 구간표·학습/검증/시험 분할 목록.
- 원본과 모델 해시, seed별 설정·학습 곡선·선택 근거.
- 기존/적응 모델 비교표와 녹화별 오류·누락·전환 지연 보고서.
- 별도 경로의 적응 모델. 출발 모델과 기존/신규 학습 자료 목록을 기록하고 예전 점수를 새 모델 점수처럼 복사하지 않는다.

**현재 결과:** 계획 작성만 완료. 다음은 **1번 수집 조건·분할·채택 기준 확정**이다.
