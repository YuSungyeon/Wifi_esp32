- 현재 GUI·CLI는 **30초 진폭(기본) / 60초 위상(시험 후보)**을 선택할 수 있다. 기존 모델·가중치를 덮어쓰지 않는다.
- 원격 main을 갱신해 `01c9f1929b170d21fe9a570bd37c821127521aeb`를 확인하고, 해당 커밋의 위상 모델 코드·가중치와 공유 CNN을 별도 경로에 가져왔다.
- 이번에 사용할 후보는 `model_train/phase60/model_60sessions.pt`다. 9/19·20의 60세션으로 학습했고, main에 기록된 9/16·17 평가 결과는 **14/15세션 정답**이다.
- `model_15sessions.pt`는 9/16·17로 학습한 모델이므로, 같은 자료를 학습하지 않은 시험 자료처럼 평가하는 데 사용하지 않는다.
- 이번 작업은 **저장된 모델 평가와 실시간 연결**이다. 새 학습, 진폭·위상 결합 모델, 펌웨어 변경은 포함하지 않는다.
- 2026-10-08 사용자 요청으로 1~2번, 10/10 요청으로 3번을 완료했다. 4번과 커밋·푸시는 별도 후속 작업이다.

### 해석할 때 주의

이 자료는 해당 저장 모델의 학습에는 들어가지 않았지만, **프로젝트에서 이전 파일럿·평가에 사용한 이력이 있다.** 처음 보는 완전히 새로운 시험이라고 부르지 않는다.

main의 `window_accuracy`는 **세션마다 구한 창 정답률의 평균**이다.
기존 진폭 보고서의 **전체 280개 창 중 234개 정답**과 계산 방식이 다르다.
위상도 전체 창 정답 수/전체 유효 창 수를 별도로 계산하되, 창 길이·간격이 다른 점을 함께 적는다.
많이 겹치는 창을 독립 시험 수처럼 세지 않는다.

**결과 기록 (2026-10-08):** main `01c9f19`에서 가져온 모델로 **14/15 재현**.
틀린 세션은 9/16 s33(정지→빈 방). 진폭이 틀렸던 s37·s43은 맞혔다.
전체 창 1,041/1,190(87.48%), 후보 1,213개 중 누락 창 23개 제외.
267파일 해시·모델 상태 불변, 테스트 146개 통과.
해시·전체 비교·재현 방법은 [평가 보고서](../../model_train/docs/model-training/20260916-17-phase60-evaluation.md)에 기록했다.

## 3번 — GUI·CLI에서 선택해 실행할 수 있게 연결

**모델 파일 경로만 바꿔서는 안 된다.** 현재 엔진은 진폭용 입력을 만들기 때문이다.

### 반드시 유지할 입력 규칙

| 항목 | 위상 모델에 넣을 값 |
|---|---|
| RX | 101 → 102 → 103, 3대 모두 필수 |
| 톤 | RX마다 `[38..63, 1..26]`의 52개, 총 156개 신호 |
| 시간 | 100Hz 기준 6,000프레임 = 60초 |
| 위상 처리 | raw I/Q → 복소수 → 주파수축 unwrap → 주파수축 직선 성분 제거 |
| 누락 처리 | 실수·허수 각각에서 5프레임 이하 내부 공백만 보간한 뒤 위상 변환 |
| 시간 줄이기 | 20개 시점씩 평균 → 300시점 |
| 정규화 | 각 신호의 창 평균 차감만. 상대 진폭 백분율 변환을 쓰지 않음 |
| 모델 입력 | `(배치, 시간, 신호)` = `(1, 300, 156)` |
| 최종 분류 | seed 0·1·2의 softmax 평균에서 가장 큰 클래스 |
| 실시간 이동 간격 | 30프레임 = 0.3초. 1번 평가의 3초 간격과 별도 설정 |
