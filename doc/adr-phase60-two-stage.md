# 위상 모델을 움직임 판정과 빈 방·정지 판정으로 나누는 설계

> 상태: **PLANNED** — 2026-10-12. 설계 작성, 구현은 추후 진행.

## 배경

새 방의 정지 신호를 빈 방으로 판단한 문제를 확인했다. 사용자는 empty/static 구분에 집중하는 모델을 두되 motion도 처리하는 2단계 구조를 먼저 설계하도록 요청했다.

## 설계 결정

1단계는 motion/non_motion, 2단계는 empty/static을 학습하는 별도 이진 모델로 구성한다. 두 단계 모두 기존 60초 위상 입력을 사용한다. 단계별 seed 3개 점수를 평균하고, 1단계 움직임 점수 0.5를 기준으로 2단계 실행 여부를 결정한다.

입력 특징 계약은 기존 위상 규칙을 재사용한다. 체크포인트와 예측 반환 형식은 새 모델 종류로 구분한다. 최종 상태는 분기 결과로 정하고 기존 세 점수의 최대값 방식으로 재계산하지 않는다.

층 구성·학습 자료·가중치 초기화·오류 전파·검증 기준의 정본은 [2단계 모델 설계](../model_train/docs/model-training/phase60-two-stage-design.md)다.

## 영향과 확인 사항

두 단계의 잘못된 분기가 최종 오판으로 이어지므로 단계별 진단과 전체 연결 결과를 함께 평가한다. 출발 모델이 이미 학습한 60세션은 새 독립 검증으로 쓰지 않는다. 다른 날 새 방 시험과 실제 전환 시험으로 성능을 확인한다.

기존 [실시간 모델 선택 결정](adr-phase60-realtime-selection.md)은 현재 구현의 기준이다. 이 설계는 새로운 후보의 후속 연결을 규정하며, 현재 선택 항목이 추가된 상태를 뜻하지 않는다.
