## 1단계 움직임 검출기와 활동량 띠 (2026-10-12 저녁)

"현재 상태를 고도화" 요청에 세 축(UI/UX · 정확도 · 모델 2분할)을 함께 봤다. 결론은 **세 축이

### 모델 2분할은 비대칭으로 해야 한다

파일럿 수치가 이미 답을 갖고 있었다: 1단계(움직임 여부, 진폭 3초) 0.987 / 13세션, 2단계
(empty·static 전용, 위상 60초) 0.852 로 3-class 의 같은 부분(0.877)보다 **나쁘다.** motion
세션이 빠지며 학습 데이터가 3분의 2로 줄기 때문이다. 그래서 1단계만 만들었다.

`model_train/amp60/train.py --task motion --window 300`, 학습 9/16·17·19 45세션(8944창),
봉인 9/20 단발 평가 **세션 30/30 · 창 정답률 0.9661** (3 seed 81초). 창 단위로는 rest 평균
0.051 / motion 평균 0.834 로 갈리고, 기준 0.90 · 연속 3창(3.6초)이면 rest 1.64시간에서
**오경보 0회**다. 배포 30초 모델이 20초 움직임도 못 잡던 것과 대비된다.

**상태 기계에는 넣지 않았다.** 창 3초와 상태 모델의 30~90초는 시간 축이 다르고, 기준값을
봉인 데이터로 고르면 그 순간 시험지가 아니게 된다. 전환 세션 수집 전까지는 화면 표시 전용이다.

### 앙상블은 기각 — 오류가 겹친다

`model_train/analysis/ensemble_test.py` (학습 불필요, 날짜 잠금 검사 포함)로 두 번 쟀다.
배포 진폭+위상 60세션 → 9/16·17 에서 12/15·14/15 가 합쳐도 14/15. 위상 v1·v3·v2 → 9/19 에서
셋 다 29/30 이고 **모든 조합이 29/30**. 창 길이가 2~3배 다른 모델 셋이 **똑같은 한 세션**에서만
틀린다. 오답이 모델 분산이 아니라 세션에서 나오므로 결합으로는 못 고친다. 특징 수준 결합은
이미 나빴다(파일럿 사이클 8). **정확도는 결합이 아니라 데이터로 올려야 한다.**

### 막힌 지점 — 실시간 스트림의 진폭이 학습 때와 달랐다

활동량 띠를 붙이자 합성 세션의 정지 구간 13% 가 "움직임"으로 나왔다. 원본 토막을 직접 재면

것이었다 — CFO 로 회전하는 성분이 상쇄돼 진폭이 0 으로 꺼진다(스트림 최솟값 0.00 대 학습 경로
1.41, 최대 차이 18.1). 공식 **위상** 경로는 성분별 보간이 맞지만 공식 **진폭** 경로는 크기를
보간한다. 스트림이 하나만 따라갔다.

고친 뒤 스트림 진폭이 학습 경로와 **1.9e-06** 까지 일치한다. 창 30초 배포 모델은 영향이 거의

## 제어판 탭 넷 — 더하는 대신 덜어내기 (2026-10-18)

"수집 따로, 실험 정보 따로라 복잡하다" 는 말에서 출발해 코드를 들여다보니 원인이 구체적이었다
— **실험 정보 12칸 중 블록마다 바뀌는 것은 3칸뿐인데 나머지 9칸 때문에 탭을 하나 통째로**
쓰고 있었다. 10-12 판 설계는 탭 7개 위에 단계 띠를 **더해** 흐름을 드러내려 했는데, 구현 전에
방향을 바꿔 **덜어내는** 쪽으로 갔다. 탭 7 → 4 (수집·세션·학습·실시간).

화면 결정은 공통 규칙 셋에서 나왔다 — 버튼이 자기가 할 일을 말한다(`static 수집 시작`,
`15세션으로 학습 시작 — 약 44분`), 거의 안 바뀌는 값은 글자 한 줄로 내린다, 문제는 막힌
자리에서 푼다(보드 점검이 수집 화면 맨 위 한 줄).

### 구현하다 드러난 것

- **품질 기준이 두 벌이었다.** 제어판 세션 표는 `seq_gap` 까지 보고, 학습 목록은 RX 3대만
  봤다. 같은 세션이 화면마다 다르게 판정됐다. `csi_session.quality()` 하나로 합쳤다.
- **학습 시간 추정이 두 군데 틀려 있었다.** `--train-stride` 기본값이 학습기마다 다른데
  (phase60 30 / amp60 150) 하나로 뭉뚱그려 창 수가 5배 틀렸고, 시간 계수가 위상으로만
  보정돼 진폭이 5배 부풀었다(5분 대 실측 62초). 학습기별 상수를 두니 네 프리셋 모두 실측과
  18% 안에서 맞는다.
- **탭을 지우자 두 가지가 조용히 끊겼다.** `/api/flash` 가 화면에서 도달 불가능해졌고
  (`보드` 탭에만 버튼이 있었다), 실시간 카드를 옮기다 `let trainPick` 선언이 통째로 지워져
  학습 탭이 죽었다. **pytest 는 JS 를 실행하지 않아 스위트는 통과했다.** 둘 다 테스트로
  묶었다 — 서버가 받는 모든 `/api/*` 가 화면 어딘가에서 불리는지, 탭이 쓰는 상태 변수가
  선언돼 있는지. 브라우저로 네 탭을 직접 눌러 보지 않았으면 못 찾았을 것들이다.
- **"봉인" 이라는 말을 쓸 수 없었다.** 시안은 9/20 을 봉인으로 적었는데 체크포인트를 열어
  보니 네 날짜 모두 이미 학습에 쓰였다(`amp1500_all74` 가 74세션 전부). 화면에는
  `이 날짜로 학습한 모델이 N개 있습니다` 라는 사실만 적는다 — 잠금이 아니라 정보다.
