## 2026-09-24 — 안정적인 3분류 후속 실험

  요구해 motion 윈도 손실이 컸다. 긴 문맥과 결측 허용 통계 경로를 별도 실험한다.
- **선행 설계**: [실험 설계](../../model_train/docs/model-training/robust-three-class-design.md)에
  성능 기준, 세션 분리, 날짜·배치 제외 평가, 새 날짜 미확보 제한을 먼저 기록했다.
- **탐색 완료**: 통계 180후보 × 5-fold, 공유 인코더 6후보 × 5-fold. 30초 상대 진폭
  공유 인코더를 최종 후보로 선택했다. 모델당 파라미터 4,731개다.
- **고정 모델 검증**: 날짜 양방향·배치 제외에서 3-seed 앙상블 session F1 모두 1.000.
  날짜별 30초 window F1은 0.9729/0.9551. 세션은 대략 5분의 판정을 모은 지표다.
- **중첩 검증**: outer 학습 세션 안에서만 설정을 선택해도 5조건 모두 초기 기준 통과.
  날짜별 seed 평균 session F1은 1.0000/0.9889, 최저 class recall 0.90.
- **확인**: raw 180개 hash, 윈도 1,124개 재구성, 저장 모델 CPU 재실행, 49회
  세션 라벨 섞기(평균 F1 0.2443), raw 3클래스 추론, 새 테스트 13개 통과.
- **산출물**: `model_train/analysis/output/20260924-robust-three-class/neural/model.pt`.
  [결과 보고서](../../model_train/docs/model-training/robust-three-class-report.md)에 실행법과 한계를 기록했다.
- **남은 검증 범위**: 새 날짜·새 환경의 독립 검증, 상태 전환과 실시간 연동.
