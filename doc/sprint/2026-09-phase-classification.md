## 2026-09-23 — 설계 문서 작성

  실험 절차가 필요하다.
- **가설**: 패킷별 주파수 방향 선형 성분을 제거한 위상이 진폭을 보완할 수 있다.
  실제 전파 정보도 제거될 수 있어 효과는 미확인이다.
- **확인**: 9/19·20의 `session.json`과 파일 목록, 원시 복소수 처리, 펌웨어의
  CSI 복사 경로, 진폭 내보내기와 모델 입력 검증을 읽었다. ESP-IDF 문서와
  PhaseFi의 위상 처리 원리를 확인했다.
- **실제 결과**: 날짜별 30세션·클래스별 10세션·RX 파일 90개, 총 60세션·180개
  `.csi` 파일을 확인했다. 이는 목록 확인이며 위상 품질 분석 결과가 아니다.
  현재 `complex_csi()`의 실수·허수 순서와 `first_word_invalid` 미보존을
  설계의 선행 처리 항목으로 기록했다.
- **설계 결과**: 보수적으로 51개 위치 사용, 두 연속 주파수 구간별 unwrap·직선 제거,
  sin/cos 표현, 공통 윈도우의 A/P/AP 비교, 9/19 학습·검증 및 9/20 test 분할안을 작성했다.
- **다음 조치**: 합성 입력으로 복소수 해석을 검증하고 train·validation 위상 품질을
  진단한다. 이번 작업은 문서 작성이며, 실행 코드·원본 데이터·펌웨어 변경은 없다.

## 2026-09-24 — 위상 처리 구현·9회 비교 학습 착수

- **사용자 확인**: 세션별 `image/`는 RX 배치와 실험 환경 설정을 기록한 자료다.
  원본 inventory에 사진 목록과 hash를 연결하며 모델 입력에는 사용하지 않는다.
- **구현**: 복소수 성분 순서 수정, 51개 위치·두 구간 위상 보정, 원형 보간,
  공통 윈도우와 train 전용 정규화, 459차원 실험 runner를 추가했다.
- **검증**: 합성 I/Q·선형 성분 제거·각도 경계·0진폭·긴 gap·중첩 정규화·CRC·RX 식별·
  날짜별 세션 집계·동일 초기 가중치 등 새 테스트 11개와 기존 전처리 26개·CNN 3개가 통과했다.
- **실측**: train 공통 윈도우 16,233 / 진폭 23,782; validation 5,520 / 5,945;
  test 24,509 / 29,582. 세 split 모두 세 클래스가 남았다. 학습 motion의 유지율이
  특히 낮아, 공통 윈도우 성능과 제외 비율을 함께 해석한다.
- **학습**: 기존 CNN 구조·3 seed·A/P/AP 총 9회. Apple MPS 사용, 모델 파라미터는
  모든 입력에서 96,483개다. 최종 test 예측은 9회 학습의 checkpoint 선택 후 계산한다.

## 2026-09-24 — 안정적인 3분류 후속 실험

- **요청**: 시간이 걸려도 안정적인 3분류 모델 학습을 완료한다.
- **기준 결과**: 앞선 9회 비교는 완료. A/P/AP session F1 평균 0.3258/0.2063/0.3770.
  empty recall은 AP도 13.33%여서 최종 채택 불가.
- **진단**: 기존 phase 캐시에는 대부분의 프레임이 남아 있지만 구간 전체 유효성을
  요구해 motion 윈도 손실이 컸다. 긴 문맥과 결측 허용 통계 경로를 별도 실험한다.
- **선행 설계**: [실험 설계](../../model_train/docs/model-training/robust-three-class-design.md)에
  성능 기준, 세션 분리, 날짜·배치 제외 평가, 새 날짜 미확보 제한을 먼저 기록했다.
- **탐색 완료**: 통계 180후보 × 5-fold, 공유 인코더 6후보 × 5-fold. 30초 상대 진폭
  공유 인코더를 최종 후보로 선택했다. 모델당 파라미터 4,731개다.
- **고정 모델 검증**: 날짜 양방향·배치 제외에서 3-seed 앙상블 session F1 모두 1.000.
  날짜별 30초 window F1은 0.9729/0.9551. 세션은 대략 5분의 판정을 모은 지표다.
- **중첩 검증**: outer 학습 세션 안에서만 설정을 선택해도 5조건 모두 초기 기준 통과.
  날짜별 seed 평균 session F1은 1.0000/0.9889, 최저 class recall 0.90.
- **확인**: raw 180개 hash, 윈도 1,124개 재구성, 저장 모델 CPU 재실행, 49회
  세션 라벨 섞기(평균 F1 0.2443), raw 3클래스 추론, 새 테스트 13개 통과.
- **산출물**: `model_train/analysis/output/20260924-robust-three-class/neural/model.pt`.
  [결과 보고서](../../model_train/docs/model-training/robust-three-class-report.md)에 실행법과 한계를 기록했다.
- **남은 검증 범위**: 새 날짜·새 환경의 독립 검증, 상태 전환과 실시간 연동.
  기존 두 날짜에서 기준을 통과한 것으로 결과의 범위를 제한한다.
