## 2026-09-23 — 설계 문서 작성

- **문제**: 진폭에 위상을 추가하면 empty/static/motion 분류가 좋아지는지 확인할
  실험 절차가 필요하다.
- **가설**: 패킷별 주파수 방향 선형 성분을 제거한 위상이 진폭을 보완할 수 있다.
  실제 전파 정보도 제거될 수 있어 효과는 미확인이다.
- **확인**: 9/19·20의 `session.json`과 파일 목록, 원시 복소수 처리, 펌웨어의
  CSI 복사 경로, 진폭 내보내기와 모델 입력 검증을 읽었다. ESP-IDF 문서와
  PhaseFi의 위상 처리 원리를 확인했다.
- **실제 결과**: 날짜별 30세션·클래스별 10세션·RX 파일 90개, 총 60세션·180개
  `.csi` 파일을 확인했다. 이는 목록 확인이며 위상 품질 분석 결과가 아니다.
  현재 `complex_csi()`의 실수·허수 순서와 `first_word_invalid` 미보존을
  설계의 선행 처리 항목으로 기록했다.
- **설계 결과**: 보수적으로 51개 위치 사용, 두 연속 주파수 구간별 unwrap·직선 제거,
  sin/cos 표현, 공통 윈도우의 A/P/AP 비교, 9/19 학습·검증 및 9/20 test 분할안을 작성했다.
- **다음 조치**: 합성 입력으로 복소수 해석을 검증하고 train·validation 위상 품질을
  진단한다. 이번 작업은 문서 작성이며, 실행 코드·원본 데이터·펌웨어 변경은 없다.
