# ADR: 진폭·위상 비교 실험의 입력 계약

> 상태: **ACCEPTED — 실험 경로에 한정**, 2026-09-24

## 배경

공식 LSTM·CNN 경로는 3 RX × 64 진폭의 192차원 입력을 검증한다. 9/19·20 데이터에서
위상의 추가 효과를 확인하려면 원본 복소수와 별도 입력 계약이 필요하다.

## 결정

- 기존 공식 192차원 CLI는 유지하고, 별도 실험 runner가 459차원 계약을 검증한다.
- 기존 `CNN1DClassifier`, 학습·평가 함수, 세션의 확률 평균 방식은 재사용한다.
- 입력은 진폭 153개·보정 위상 sin 153개·cos 153개다. A/P/AP는 정규화 후 불필요한
  입력을 0으로 만들어 같은 모델 구조에서 비교한다.
- 수집 형식과 원본 파일은 유지한다. RX당 51개 위치 선택과 위상 보정은 호스트에서 수행한다.
- 세션별 정렬 배열과 윈도우 시작 위치를 저장한다. 겹친 윈도우를 디스크에 반복 복제하지 않는다.
- 세션의 `image/`는 RX 배치·환경 설정의 근거 자료다. 이미지·메타데이터를 모델 특징에 넣지 않는다.

## 영향

기존 모델 재현 경로와 실험 경로를 구분할 수 있다. 새 checkpoint는 feature 버전,
RX·주파수 순서, 정규화와 윈도우 목록의 hash를 확인해야 사용할 수 있다.
`complex_csi()`의 실수·허수 순서 수정으로 과거 위상 캐시는 새 실험에서 재사용하지 않는다.
진폭 계산값과 기존 진폭 모델 입력은 이 수정의 영향을 받지 않는다.

상세 기준은 [실험 설계](../model_train/docs/model-training/amplitude-phase-classification-design.md)를 따른다.
