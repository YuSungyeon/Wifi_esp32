# 측정·진단 방법론 함정

> 이 파일의 항목은 하드웨어가 아니라 **재는 방법**이 틀렸던 사례다. 코드 버그보다 찾기 어렵다.

## 2026-08-26 — "호스트 없을 때 콜백 881Hz" — 측정 스크립트가 백로그 IDENT 를 읽음

- **증상**: 포트를 닫았다 여는 실험에서 Δcsi_cb 가 17,620 / ~20초 = 881Hz. 이상 현상으로 의심.
- **원인**: 애드혹 `peek()` 이 포트를 열자마자 첫 IDENT 를 읽었는데 그게 백로그의 오래된
  IDENT — 카운터 스냅샷 시점이 실제보다 한참 과거라 델타가 부풀었다.
- **재측정**: `Δcsi_cb ≈ Δseq` 교차 검증으로 두 조건 모두 ~100Hz. 백로그 프레임을 뜯어봐도
  `tx_seq` 1씩 증가하는 정상 TX 프레임.
- **교훈**: 라이브 스트림을 임시로 볼 때 **반드시 백로그를 먼저 비운다.** 수집 경로는 그렇게
  하지만 애드혹 스크립트는 잊는다.

## 2026-08-26 — 매니페스트 Hz 가 낮게 보임 (78.4Hz)

- **원인**: 호스트 wall clock 으로 Hz 를 계산해 백로그 비우기·기동 시간이 섞임.
- **해결**: 보드 타임스탬프 기준 `span_s` 기록 → 99.7Hz.

## 2026-09-02 — 무선 업링크 첫 측정 51Hz·46% 손실 — 또 백로그

- **증상**: 싱크 포트 15초 캡처에 1831프레임, 보드 시계 span 35.7s, `seq_gap=1731`.
- **원인**: 위와 같은 함정. 싱크 백로그(링버퍼 + USB 버퍼)를 먼저 읽었다.
  이미 문서에 적어둔 함정을 또 밟았다.
- **재측정**(백로그 비운 뒤): 99.5Hz, 손실 0%, `uplink_fail=0`.

## 2026-09-02 — AUC 가 거짓말을 함 (분리 진단 도구)

- **증상**: 세 클래스가 **통계적으로 완전히 동일한** 합성 데이터에서 `action vs empty`
  AUC **1.000**.
- **원인**: 모든 세션의 윈도를 한데 모아 계산하므로 세션마다 다른 기저 채널이 클래스 차이처럼
  보인다. 같은 데이터에서 세션 단위 LOSO 는 0.583.
- **해결**: 판정 기준을 **쌍별 2-class 세션 단위 LOSO** 로. AUC 는 "참고 — 부풀려진 값" 표기.
- **함의**: 수집 프로토콜의 라운드로빈·조건 교차 규칙의 근거 ([collection-protocol.md](../collection-protocol.md) §1).

## 2026-09-02 — 잡음 특징이 최근접 중심 판정을 뒤집음

- **증상**: 분리 가능한 데이터인데 LOSO 정확도가 정확히 우연(0.333), empty↔static 완전 맞바뀜.
- **원인**: `서브캐리어 분산` 은 배치가 만든 세션 지문이라 같은 클래스의 다른 세션끼리 값이
  널뛰는데, 5차원 유클리드 거리에서 유효 특징과 동등한 표를 행사.
- **해결**: 특징별 LOSO 정확도 + **세션지문 지표**(같은 클래스 안 세션 간 흩어짐 / 클래스 간
  흩어짐)로 자동 제외. 수정 후 1.000.
- **알려진 성질**: 그룹이 2개뿐이면 필터가 공격적이라 특징이 1개만 남는다. 파일럿 규모에서 정상.

## 2026-09-02 — ablation 정직성 확인

- 합성 위상은 순수 잡음인데 `amp52+phase` 가 amp52 보다 낮게(1.000→0.916). 잡음 특징을
  넣으면 나빠진다는 걸 하네스가 감추지 않는다 — 의도된 결과.

## 2026-09-03 — `--identify` 가 재플래시 직후 옛 `rx_id` 를 보고

- **증상**: RX103 을 `rx_id=1` 로 재플래시했는데 싱크 포트 `--identify` 가 `rx_id=0`.
  실제 수집으로 확인하니 CSI·IDENT 모두 `rx_id=1`, `boot_id` 새 값.
- **원인**: identify 모드가 포트를 열자마자 첫 IDENT 를 읽고 끝냈다 — 싱크 링버퍼에 남은
  재플래시 **이전** 프레임. 이 파일 첫 항목과 같은 함정을 도구 자체가 밟았다.
- **해결**: 같은 MAC 의 IDENT 는 항상 마지막 값으로 덮어쓰고, 최소 1초는 읽어 백로그가
  마르게 한 뒤 판정.
- **재발 방지**: 규칙 1 은 애드혹 스크립트뿐 아니라 **`--identify` 처럼 짧게 여는 도구**에도
  적용된다.

## 규칙

1. 라이브 스트림은 백로그부터 비운다.
2. 카운터는 누적이 아니라 **구간 델타**로 보고, 서로 다른 카운터를 교차 검증한다(`Δcsi_cb ≈ Δseq`).
3. 시간은 호스트 벽시계가 아니라 보드 타임스탬프로 잰다.
4. 분리도는 세션 혼합 AUC 가 아니라 세션/조건 단위 LOSO 로 판정한다.
5. 수치가 이상하면 카운터가 아니라 **원시 바이트**를 본다 ([02](02-serial-stream.md) 2026-09-02).
