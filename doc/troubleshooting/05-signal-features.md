# 신호 처리·특징

## 2026-08-25 — `csi_amp[:52]` 가 상시 0 서브캐리어 12개를 포함

- **증상**: 실측 평균 진폭 — 인덱스 0 과 27~37 이 0.0~0.1, 나머지는 9~16.
  ```
   0- 7:   0.1  15.7  15.3  14.7  14.9  14.1  13.6  13.2
  24-31:   9.5   9.2   8.7   0.0   0.1   0.1   0.1   0.1
  32-39:   0.0   0.1   0.1   0.1   0.1   0.0  12.3  12.5
  ```
- **원인**: HT20 LLTF 64 SC 중 0(DC)·27~37(가드)은 상시 0. `[:52]` 는 이 12개를 넣고 실제
  데이터인 52~63 을 버린다 → feature 23% 상수 0, 유효 톤 23% 유실.
- **해결**: `csi_store.LLTF_DATA_IDX = [1..26] + [38..63]` (52개). 동일 데이터에서 상수 컬럼
  12/52 → **0/52**. 실보드에서도 상시 0 인덱스가 정확히 `[0, 27..37]`.
- **미결**: 모델 레포의 `preprocess_3rx.py` 는 `features_per_rx=64` — 3-RX 192 중 36개(19%)
  상수 0. 52 vs 64 결정은 모델 담당과 합의 필요 (제안: 기본 52, 64 는 ablation).

## 2026-08-26 — gain 보정 — 되돌림

- **문제**: AGC 가 게인을 바꾸면 raw 진폭이 계단식으로 뛸 것이라 예상. 실측상 45초에 AGC 483회,
  FFT gain 8~23단계 변동.
- **시도 1** — 근사식 `2^-((fft-fft0)+(agc-agc0)/4)`: 시간축 std 0.636 → **8.355**, 13배 악화. 즉시 폐기.
- **시도 2** — 벤더 `esp_csi_gain_ctrl`: 소스 없이 `.a` 로만 배포되어 호스트 이식 불가.
  보드에서 계산해 `gain_comp`(f32)를 헤더에 싣도록 v3→**v4**(44B).
  | 지표 | 보정 전 | 보정 후 |
  |---|---|---|
  | 시간축 std | 0.636 | 1.280 |
  | AGC 변화 483곳 진폭 점프 | 0.58 | 0.59 |
- **해석**: AGC 변화 지점 점프 0.58 은 평균 진폭 13 의 4% — 프레임간 변동과 구분 안 됨.
  **보정할 계단이 애초에 없다** (`manu_scale=false` 로 HW 가 이미 스케일링하는 것으로 보임).
- **결정**: `amplitude(compensate=False)` 기본. 필드는 계속 저장 — 수신기 이동·RSSI 급변
  조건에서 재검토하려면 데이터가 남아 있어야 한다.

## 2026-09-02 — 위상 ablation 이 재수집 없이 가능해짐

- `.csi` 가 raw I/Q 를 보존하므로 `ablation.py --features amp52+phase`. 위상 특징은 인접
  서브캐리어 위상차(CFO 상쇄)의 시간축 변동 — 조악한 베이스라인용. 정식 sanitization 은 모델 과제.
